# GitHub 协作文件

- issue、dev 开发、main 人工合并的流程以根 AGENTS.md 和 docs/project/contribution-workflow.md 为准。
- Pull Request 模板依次包含关联 Issue、变更类型、问题与目标、变更摘要、影响与兼容性、文档与素材、验证结果、审查提示。变更类型附简短含义，可按实际改动多选；验证填写实际结果，不预填通过。
- 完成既定验收后使用仓库 skill farm-exchange-submit-pr 自动提交、推送 dev、创建关联 issue 的 dev → main PR；不自行合并。
