# 大小地图功能规划

关联 [#153：大小地图导航与键鼠操作登记](https://github.com/Fotally/Farm-Exchange/issues/153)。状态：**已接入正式游戏；执行状态、验收证据与 PR 以关联议题为准**。本页集中维护计划范围；[研究依据](../research/minimap-navigation.md)、[1080P 原型](../architecture/ui/main/prototype-maps.md)和[键鼠登记](input-bindings.md)分别维护证据、演示与键位。现行游戏行为仍以[地图与镜头](../gameplay/world/map-and-camera.md)为准。

## 已确认的功能范围

| 项目 | 计划行为 |
| --- | --- |
| 设计基准 | 至少 1920×1080，沿用木框纸面主题；采用已查看的 B 全屏地图方向与等距示意作为视觉基准，具体布局尺寸仍需正式适配 |
| 左下角小地图 | 常驻、固定显示全图，视野框标出主镜头当前看到的范围；左键点击／拖动移动主镜头，单击不展开大地图 |
| 大地图开关 | M 或小地图旁展开按钮打开，M／Esc／返回按钮关闭 |
| 大地图导航 | 左键短按定位主镜头并保持大地图打开；按住左键拖动只浏览大地图底图，拖动结束不定位，即使移回按下点也不定位 |
| 辅助浏览 | 保留原型中的右键拖动作为辅助平移操作，不替代左键拖动 |
| 缩放 | 大地图首次打开显示全图，滚轮缩放查看局部；独立于主镜头倍率，小地图保持全图 |
| 经营时间 | 打开大地图不暂停经营；开关地图不修改既有暂停状态，原本运行则继续运行、原本暂停则保持暂停 |
| 查看状态记忆 | 本次游戏内关闭再打开大地图恢复倍率和查看位置；新开一局重置二者，首次打开恢复全图；不增加跨游戏启动保存 |
| 文字表现 | 大地图去除“中心农场／西侧种植区／东侧种植区”等区域名称与底色标签，保留必要操作提示、图例和视野框 |
| 键位管理 | 维护键位、动作、生效上下文、冲突与实现入口表；后续新增输入先核对该表 |

## 原型与正式实现的界限

B 全屏方向已作为本阶段设计基线，A／C 仅作对照。原型以 1848×962 面板留出演示工具条，正式游戏不照搬 A／B／C 切换条、演示状态栏、左右方向键切换布局或模拟农场数据。“全屏地图”表示游戏内地图界面，不新增切换操作系统全屏的快捷键。

小地图尺寸按真实 1080P 排版适配；短按与拖动沿用主镜头 8 个逻辑视口像素的判定尺度。缩放与辅助控件按下表已确认规则实现。倍率与查看位置记忆、新局重置和开关地图不改变暂停状态仍须正式验收；浏览器刷新重置不代替真实新局验收。

## 已确认的实施规则

2026-10-15 确认以下规则，现行玩家操作见[地图与镜头](../gameplay/world/map-and-camera.md)，模块约定见[大小地图 Interface](../architecture/ui/map-navigation/interface-map-navigation.md)。

| 项目 | 正式实施规则 | 接入约束 |
| --- | --- | --- |
| 窗口与建造共存 | 文字编辑时不响应 M；确认框打开时禁止打开大地图；大地图覆盖并保留已有窗口，打开时取消建造候选及未完成道路段，关闭后不恢复工具 | 屏蔽背景键鼠操作；M 忽略自动重复和修饰键；Esc 只关闭大地图。#136 已完成，保留编辑焦点回归 |
| 手势捕获 | 拖出控件继续捕获至松开；离窗、失焦或关闭结束手势，不触发定位 | 一旦成为拖动，回到按下点仍不短按定位 |
| 显示内容与辨识 | 显示真实陆地、水域、农田、加工场地和道路，以颜色区分并保证缩小后设施和道路可辨；首版不显示工人、天气 | #110 已完成；读取既有权威地形，不实现新地形规则 |
| 缩放与辅助控件 | 全图适配为 1 倍，范围 1～12 倍；滚轮以鼠标为锚点，每档乘／除 1.25；加减按钮以视图中心缩放，提供全图与定位当前镜头按钮；小地图吞掉滚轮 | 全图按钮恢复 1 倍并居中；定位当前镜头保持大地图倍率 |
| 地图边缘和视野框 | 菱形外点击忽略；拖动浏览中心限制在地图内；视野框表示完整渲染视口，不扣除 UI 遮挡 | 主镜头定位沿用真实镜头边界约束；缩放和窗口变化同步视野框 |

## 后续实现的最小职责边界

以下用于避免遗漏和重复状态，不预先引入通用输入框架或新增经营能力：

- 地图只读取真实空间、设施分类和镜头状态，保存自身显示、缩放、浏览位置与手势状态；不维护第二份土地占用、工人调度或生产状态。
- 小地图导航与大地图短按共用现有主镜头定位和边界约束；大地图平移及缩放只改变自己的视图。
- 视野框来自实际镜头和视口变换，表示完整渲染视口。主镜头平移、缩放、窗口大小改变时同步，不能使用固定大小的演示框。
- 静态底图按真实空间／地形变化更新，视野框独立刷新；建造、拆除后显示真实结果，失败和预览不当成建成设施。具体刷新策略在接入现有快照后确定，不为浏览再运行一套经营。
- 原型不承载正式输入集成：鼠标按下、移动、松开、跨界面、离窗、失焦、关闭地图要保持正确归属；字母键需要考虑编辑焦点、修饰键和自动重复。

## 验收项目

- 在真实主场景 1920×1080 下核对左下角小地图、B 全屏方向、图例和无区域标签；整体 UI／字体倍率及窗口扩大符合现行缩放规则。
- 全图、四角、边缘及不同主镜头倍率下，大小地图坐标、主镜头跳转和实际视野框一致；窗口改变后仍正确。
- 小地图点击／拖动导航，大地图短按定位、左拖浏览互斥；拖回起点、控件外释放、失焦、关闭均不误定位或遗留拖动。
- 大地图滚轮与辅助右拖不改变主镜头倍率；首次打开显示全图，同次游戏关闭重开恢复倍率和查看位置；新开一局重置两项状态，再次首次打开显示全图。
- M 自动重复、输入框内 M／R／WASD、修饰键和确认框不产生双重动作；打开地图取消建造模式与未完成道路段，保留已有窗口，关闭不恢复工具；Esc 不同时关闭背景窗口。
- 地图变化读取真实状态；建拆成功、失败及预览区分正确；开局少量设施、密集农场和道路均按最终图层口径辨认。
- 原本运行时打开大地图经营继续推进，关闭不改变运行状态；原本暂停时打开／关闭地图均保持暂停。
- 满地图 16,384 生产实例与连续导航／缩放进行正式负载和图形验收：平均至少 60 FPS，P95 帧间隔不超过 16.67 ms，保存前后截图；浏览器原型不代替该结果。
- 按仓库既有编译、测试／覆盖率、Windows Release 导出与运行闭环验收。
