# 当前玩法人工验收

1. 运行游戏，确认等距地图、顶部金币和工人状态、底部单一“建造”入口、库存及市场入口。界面不显示内部 tick、天数或免费选地次数。左键短按选格，左键拖动、滚轮和 WASD 浏览地图；拖动松开后镜头停止，再次短按可选格。
2. 地图中心应有 3 块未播种农田和 2 处配套加工场地。初始金币为 50.00，五座预置建筑不扣费。可能是三块同种，也可能是两块同种加一块另一种；加工场地与农田作物匹配。
3. 点击底部“建造”，在目录切换“农田”和“加工场地”，使用搜索框筛选具体加工场地。选中“农田”后，点击空地直接建成，金币减少 10.00；选择加工场地后同样摆放。点击已有建筑应提示无法建造且不扣费。按 Esc 或点击“取消摆放”退出摆放。
4. 点击农田，右侧详情显示作物状态、原料当日售价、该种公共原料库存和“生长周期：浇水后 N 秒成熟”，不显示加工品库存。小麦显示 5 秒；点击“更换作物”，选种列表只显示各作物的原料价格和库存；选择玉米后农田显示 6 秒，生长中的旧作物消失。其他作物依[作物表](../gameplay/production/crop-growth.md)显示 7、6、9、10 秒。详情、作物列表、建造目录、库存和市场窗口均可从标题栏拖动，关闭再打开仍停在本次运行最后的位置；重启后回到默认位置。
5. 点击加工场地，右侧详情显示加工状态、对应原料与加工品、加工周期、加工品当日售价及该种公共加工品库存，不显示农田生长周期或原料售价。玉米加工坊显示投入原料后 4 秒完成；等待工人播种、浇水、收获后，确认场地状态与加工品库存随生产刷新，售价随换日刷新。库存窗口显示六种原料和加工品的数量。市场分别显示原料与加工品价格，可出售全部加工品并更新金币。把一块农田改种为没有对应加工场地的作物，待原料积累后在市场按品种卖出，确认该种原料库存归零、金币按当日售价增加；已投入加工的原料不会列入可售库存。
6. 移除正在加工的场地，已投入原料消失；移除生长中的农田，未收获作物消失。移除不退款，在原格重建仍收 10.00 金币。
7. 地图边缘应呈菱形，边界外没有地块，镜头中心不能移出地图范围。视窗变化后，已打开窗口的标题栏仍可抓取。

当前版本有六种作物、配套加工循环与原料销售。年月和市场每周波动仍由 [issue #25](https://github.com/Fotally/Farm-Exchange/issues/25) 讨论；存档与离线收益尚待确认。
