# 当前玩法人工验收

1. 运行游戏，确认等距地图、顶部金币、工人和“春 · 第 1 年 · 1 月 · 1 日”、底部“建造”入口、库存及市场入口。界面不显示内部 tick。点击“暂停”后经营和日期停止，点击“继续”恢复；窗口失焦不会自动暂停。左键短按选格，左键拖动、滚轮和 WASD 浏览地图；拖动松开后镜头停止，再次短按可选格。
2. 地图为 384×384 基础格，每格 64×32 世界像素；中心有 3 座未播种农田和 2 处加工场地，各占 3×3（192×96），道路仅占一格。顶部显示“3 · 自动照料”；三人出生于农田中间格 (190,190)、(193,190)、(196,190)，保持原角色尺寸。初始金币 50.00、五座预置设施免费；开局同种或 2+1 配置与对应加工关系保持。
3. 点击底部“建造”，在目录切换“农田”“加工场地”“道路”，使用搜索框筛选具体加工场地。选中“农田”后，点击空地直接建成，金币减少 10.00；选择加工场地后同样摆放，成功后退出模式。道路灰色卡片显示每格 1.00 金币，选择后连续点击两个空格，地图各出现灰色路面，金币每格分别减少 1.00，铺设模式保持；再点击已有道路、农田或加工场地应提示无法建造、不覆盖、不扣费且继续保持模式。按 Esc 或点击“取消摆放”退出；退出后点击道路打开独立详情，只显示当前布局用途与拆除不退款说明，没有作物、加工周期或库存。点击“拆除道路”确认原格恢复空地、相邻道路保持且金币不增加。
4. 点击农田，右侧详情显示作物状态、原料当前报价、该种公共原料库存和“生长周期：获得水后 N 天成熟”，不显示加工品库存。小麦显示 16 天；点击“更换作物”，选种列表只显示各作物的原料价格和库存；选择萝卜后农田显示 4 天，生长中的旧作物消失，田块原有水分保留。在初始春季选择甘蔗，详情应显示“当前季节不适宜播种”，工人不播种；改为萝卜后可恢复播种。其他时长与适宜季节依[作物表](../gameplay/production/crop-growth.md)。详情、作物列表、建造目录、库存和市场窗口均可从标题栏拖动，关闭再打开仍停在本次运行最后的位置；重启后回到默认位置。
5. 点击加工场地，右侧详情显示加工状态、对应原料与加工品、加工周期、加工品当前报价及该种公共加工品库存，不显示农田生长周期或原料售价。腌制坊显示投入原料后 0.5 天完成；等待工人播种、浇水、收获后，确认场地状态与加工品库存随生产刷新，报价只在实际报价日变化，普通日期不变。库存窗口显示七种原料和加工品的数量。市场分别显示原料与加工品价格，可出售全部加工品并更新金币。把一块农田改种为没有对应加工场地的作物，待原料积累后在市场按品种卖出，确认该种原料库存归零、金币按执行时当前报价增加；已投入加工的原料不会列入可售库存。
6. 分别点击同一农田的九个子格，确认都选中整座并显示同一详情；从非锚点子格改种只改变这一座。从非锚点子格拆除农田或加工场地，九格应全部恢复空地，选框不残留；未收获作物或已投入加工原料消失，不退款。在任意释放的空小格重建仍收一座 10.00；试在地图最后两列/行作生产设施锚点，或只让远端子格覆盖道路，均应整次拒绝且金币、占用不变。
7. 地图边缘应呈菱形，边界外没有地块，镜头中心不能移出地图范围。视窗变化后，已打开窗口的标题栏仍可抓取。
8. 在中心附近和稍远处建造适季农田，观察三人各自走向整座田的中间格，每秒移动 3 小格（一个标准田跨度）；同一座田不应按子格重复认领。无路也能直线穿过建筑，到达后播种及干田浇水各占完整经营秒，供水后进入生长；湿田省去浇水，停在最后实际位置。移动中暂停后位置与动画停止，恢复不补算暂停时长；镜头移开后经营照常。改种或拆除途中目标、在同锚点重建后，旧动作不得作用于新对象。成熟时只收获一座田的正常产量，不能因九子格增加九倍。

当前版本包含十四商品独立双周报价及同价零手续费即时交易，方案见[市场规则](market-proposal.md)；存档与离线收益尚待确认。

9. 打开市场，确认十四商品均显示现价、上次价、实际涨跌和公共库存，本次/下次报价显示完整年月日。选择萝卜原料输入 2，先暂停经营，再买入，金币按当前报价扣除、公共原料增加 2、日期与生产不变；卖出 2 后余额和库存恢复。选择加工品也可按数量买卖。输入 0、负数、小数、空白、超 int 最大值应显示错误并保持金币库存；合法但资金或库存不足时窗口与全局提示正常失败。选中商品全售忽略数量草稿；原料行七个快捷和全部加工品按钮均真实可用。已投入加工的原料不进入可售库存。
10. 市场数量输入保留未提交文本，将光标放在中间并滚动行情表，等待经营更新：选择、草稿、焦点、光标和表滚动不能重置。关闭再打开仍保留草稿、选择和位置。等实际报价跨期后执行买卖，金额按执行时生效报价结算。消息在报价前一日公布，标明公布日和对应报价日，十五条真实因素可在独立消息区滚动查看；夏庆日与丰收日公告包含改期原因。市场窗口不能越出 1280×720 视窗或遮住顶部/底部区域，数量标题与成交反馈保持单行，长公告消息不能挤出固定数量操作，十四商品最后一行可正常滚到完整可见。

11. 暂停后从市场打开委托窗口，选择一种商品、一次买入、限价数量方式，填写足够的最高单价和数量；设置现金保留比例，保存后确认显示原设单现金、锁定保留金额与含费冻结额度。暂停期间不成交；编辑价格和条件后保留原现金基准。尝试创建超过可用资金的买单，单据与余额应保持；已有冻结资金不能用于建造或即时买入。撤销后冻结释放，但不收费。
12. 创建一次固定总预算买单，确认提交只冻结预算、不立即买入。条件满足并恢复经营后，按实际报价计算预算可支付的完整整数数量，扣实际货值及 1% 向上取分费用，剩余冻结额度释放，单据完成且不再次成交。一次目标库存单建单时锁定差额；后续库存变化不能改变已锁数量。
13. 买入或生产一些商品后创建一次卖单，确认总库存不减少但可用库存减少，市场可售快捷不使用冻结部分；对应原料不能再被加工领取。条件满足后完整出售冻结数量，按实际收入扣费；撤销则恢复可用库存。主动即时买卖仍同价零费，全部出售只处理可用量。
14. 创建持续策略：一组条件同时要求满意价格和库存门槛，再添加另一组价格、库存与可选季节条件。确认组内全部、组间任一，多个组同时满足不会同秒重复成交；所有组的价格要求均不满足时，即使积压也等待。持续策略不冻结，目标库存每次动态计算；停用后不执行，恢复后下一经营秒继续。编辑器输入一段未提交草稿、设置光标后等待刷新，草稿、焦点、光标与滚动位置应保持。窗口底部操作和长条件列表可滚动到达，订单详情显示真实等待原因、最近成交货值、费用与成交后余额。完整规则见[委托与自动交易](../gameplay/trading/orders.md)。

15. 开局打开耕作表，创建具名年度表。将作物拖入春、夏、秋、冬四行时间图，确认一条表示一轮、长度为完整生长周期；完整直条预览中心跟随鼠标，落位起点与预览左端日期一致，跨季拆分、冬末跨春仍是一轮。重新拖动任一片段时移动整条；移除后留下休耕空白。时间带、作物条与轮廓为圆角，月份之间每七日显示周刻度；可容纳的信息在条内居中，短条或窄片段悬停显示整轮周期与起止日期，移开消失。新增与移动时，同格叠加、部分覆盖、年度首尾重叠或不同作物间距不足一天均在落位前拒绝并显示原因；原条、草稿和正式表保持。验证同种相邻、异种一天间距及替换自身可落位；冬季玉米起点拒绝，夏末玉米跨入禁生季仍可保留并提示风险。不自动移动或改种。
16. 首次开窗未命名时即可拖入合法作物并移动草稿，保存时仍明确要求名称；清空已保存表的名称后也可编辑，但不能提交。选择表级执行方式，批量勾选多块农田应用同一表，确认普通、勾选、悬停和焦点文字在浅底上均清楚可读，并显示引用范围及各田独立实际进度。应用或编辑共享表时保留正在种植的一轮；以后“立即改种”按计划日期切换或休耕，“预备下一轮”保留本轮并按预计完成时间接续。空白不播种，每条只执行一轮，错过的条不补种，年度安排重复。删除本年已执行条并保存空表、重新选择该表后新增本年未来日期条，确认新条使用新编号并仍安排在本年；移动原条仍保留编号与本年已执行凭据，不重复播种。暂停后编辑和查看不会推进日期，未提交名称、条目和选择草稿在刷新时保留。
17. 在引用表的农田分别使用“立即改种”和“预备下一轮”，操作前应显示解除本田安排的影响；立即改种还告知未收获作物损失。立即改种包括同种重启且保水；预备下一轮保留当前轮、结束后采用手动目标并自动复种。两者不增加一天休耕等待，不影响共享表或其他引用农田，实际播种浇水仍由工人完成。当前适季但预计来不及成熟时可播种并提示风险，当前禁生季节仍不可播种。

18. 在目录选择农田、加工场地或道路，移到地图确认完整占地跟随鼠标、淡绿色半透明格与类型标记；部分重叠时仅冲突格红色，边缘越界部分红色。底部显示标准费用与占地数量；可用金币不足时费用标红并显示可用金额。每次点击只建一座，成功后继续摆放且不弹详情。
19. 摆放时测试右键、Esc、取消按钮，均清除类型与预览；切换类型后重复。左键拖镜头松开不建，界面上隐藏预览，跨界面的按下/松开不建；滚轮、键盘平移与窗口尺寸变化后仍定位在当前鼠标下。暂停不因进入摆放改变，暂停时仍可主动建造；单纯预览和取消不改变金币、冻结资源、库存或日期。
