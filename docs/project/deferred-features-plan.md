## 季节耕作表：#42

**本轮状态（2026-10-03）：**用户授权的[季节耕作表方案](seasonal-cultivation-proposal.md)及 #42 验收标准均已完成，独立审查与完整构建运行验收通过，交付状态见顶部。

**已确认范围：**开局可用，多田共用每年重复的年度时间表；四季四行，一条一轮，长度为完整生长周期。拖动预览保持直条，放下后跨季拆分。空白休耕，不同作物在表中至少间隔一天。整表统一选择“立即改种”或“预备下一轮”，按日期定位，过去的条跳过；预备安排按当前作物预计完成时间缓存，变更时更新。手动两种指令独立、最高优先级，接管本田且没有额外休耕等待。耕作表不包含自动买卖。

**已确认规则调整：**手动和计划共用播种规则，当前适季即可播种，预计时间不足只提示风险；进入禁生季节时，剩余生长时间严格小于完整周期 10% 的生长中作物立刻成熟，后续沿用收获入库流程，其余未成熟作物清除。补救机制记录在内部文档，不向玩家展示阈值或专门提示；适季跨季不触发。

**接入位置：**计划模块集中持有共享配置、农田引用与预备安排；农田继续持有生产状态，经营入口协调日期事件与原有成熟、收获、入库流程，工人继续执行播种浇水；不预建通用计划语言。

**本轮验收：**年度循环、跨季拖动、多田引用、两种模式、两种手动指令、休耕与跳过、完成时间缓存、统一播种和禁生边界 10% 条件均有回归检查；独立审查、逐模块覆盖率和完整构建运行闭环已通过，详见[测试记录](testing.md#2026-10-03-42-年度耕作表验收)。

## 委托挂单、自动买卖与手续费：#36

**已确认方向：**玩家可通过委托或预设策略减少频繁查看市场；委托按实际成交额收 1% 向上取分费用。现行即时交易仍按已完成的同价零费规则执行。

**本轮进度（2026-10-02）：**完整功能已通过独立复审与本地验收，由 `orders_core` 实现完整结算、冻结与经营接入，`orders_ui` 实现条件编辑与订单管理。现金保留固定金额或原设单现金比例锁定；成交手续费 1% 向上取分；一次挂单冻结、持续不冻结；一次买单支持固定总预算或限价数量，目标差额一次锁定/持续动态算。每秒行情更新后按建单顺序完整执行，暂停不执行。季节只作读取日历的条件，深入设计见 [#80](https://github.com/Fotally/Farm-Exchange/issues/80)，本项不讨论报价可预测性、价格公式、保质期或纯交易盈利平衡。完整范围见[已确认实施方案](advanced-trading-proposal.md)及 #36 最新确认段；交付及合并状态见顶部记录。

**确认来源：**用户已选择条件组合、数量、相位、暂停、费用与冻结规则；成交后重复执行属于本游戏持续策略，不等同于股票长期有效委托。历史讨论与本轮确认见 [#36](https://github.com/Fotally/Farm-Exchange/issues/36)。

**本轮验收重点：**

- 多条件组合、两种一次买单、一次目标数量锁定及持续差额计算。
- 冻结、撤销和同 ID 编辑，失败零修改；建造、加工与主动交易不能用冻结资源。
- 1% 实际成交费用向上取分、原现金基准锁定、整数容量预检。
- 每秒建单顺序、每单一次、完整成交、资金或库存不足等待，暂停只编辑。
- 固定控件刷新保留草稿、焦点与光标，状态与费用来自真实结果。

**接入位置：**订单模块拥有单据与策略状态，使用 `TradingService` 完整结算；`Wallet` 与 `Inventory` 唯一持有实际总量与冻结额度。经营入口在行情更新后推进订单，UI 只发出意图并读取快照。

**后续验收方向：**按最终规则验证触发、成交、撤销、费用和执行顺序；资金与实物守恒、失败零修改，不重复成交、不产生负库存；时间和暂停行为与届时生效规则一致。

## 行情学习反馈：#44

**已确认方向：**前期帮助玩家适应消息、判断行情并买卖商品，熟悉后再扩展到产能规划；不因此推迟季节耕作表的可用时间。

**仍属建议：**报价后回看消息、实际涨跌与交易结果，以及引导目标、行情复盘、交易收益展示，均尚未获实施确认。

**启动前需确认：**

- 消息预测性与不确定性的表达，以及提示强度。
- 是否添加回看、复盘、收益展示或引导目标，采用什么记录与交互方式。
- 初期商品数量与引导方式是否调整，具体影响范围和验收标准。

**接入位置：**复用 `MarketQuotes` 的真实消息与报价数据；若需要交易结果记录，确认内容与保留周期后再设计。报价公式和事件规则由市场专题维护，反馈功能不新增提前播报，不事后编造因素解释。

**后续验收方向：**展示可追溯到真实消息、实际报价和玩家交易；提示强度与可见内容符合最终确认；不改变报价与公告时点，不让查询推进经营或抽取事件。
