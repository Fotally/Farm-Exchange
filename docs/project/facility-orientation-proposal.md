# 设施朝向与四向素材实施范围

关联 [#111](https://github.com/Fotally/Farm-Exchange/issues/111)，归属 [#105](https://github.com/Fotally/Farm-Exchange/issues/105)。2026-10-11 已确认下列规则。本页维护实施范围，交付证据和合入状态维护在 #111 顶部。

## 已确认交互与生命周期

- 农田及七种加工设施只在摆放前，通过 R 或“旋转”按钮按 q0→q1→q2→q3→q0 切换。建成后不提供旋转操作。
- 每一座候选最开始均为 q0，包括切换类型、取消后重选，以及成功建造后开始下一座。失败建造保留当前候选；不沿用上一座已建实例的方向。
- 旋转免费；正式建造仍按现行费用结算。暂停不阻止摆放与建造，倍率不改变命令含义；输入字段编辑期间不抢占 R。
- 当前农田/加工占地固定 3×3、工作偏移 `(1,1)`，各方向占地与工作中心相同。生产、任务、库存、年度表等经营规则不因朝向改变。
- 未来引入 3×4 等非方形设施时，方向必须同步改变实际占地；本单不新增未引入尺寸或任意形状框架。
- 开局设施为 q0。拆除移除整实例及其方向；重建使用当次候选请求。存档规则仍在后续范围，本单不引入保存框架。

玩家长期操作见[建造](../gameplay/land/opening-and-building.md)，场景入口见[主界面接口](../architecture/ui/main/interface-main.md)。

## Module 状态归属与最小 Interface

`LandOccupancy` 在同一锚点实例登记朝向，通过不可变 `BuildingSpaceSnapshot.Orientation` 只读提供；不维护第二份方向字典。`BuildingFootprint` 继续唯一定义实际占地与工作格。`Main` 只持有尚未建成候选的方向。

- `FarmGame.CheckPlacement` 与 `TryPlace` 接收合法 `BuildingOrientation`，预检与执行共用类型、方向、完整占地及资金检查。旧调用默认 q0；非法方向正常拒绝，失败资源零修改。
- 正式执行一次完成实例登记及现行费用结算，任一子格查询同一实例方向。没有建成后朝向设置命令，也不需要朝向更新专用身份机制。
- `WorldMap` 内部封装方向选图、pivot、外观缓存及动效采用；候选方向与正式建造请求保持一致。UI不直接改Sprite，也不拼接实例登记与纹理提交。
- 道路没有手动旋转入口；自动连接外观另由 #143 处理。

对应现行接口见[放置规则](../architecture/land/placement-rules/interface-placement-rules.md)、[经营入口](../architecture/game-state/farm-game/interface-farm-game.md)及[地图](../architecture/world/world-map/interface-world-map.md)。

## 素材方向与层级

来源为[清亮v2](../research/bright-complete-v2.md)包根下 `default/static/manifest.json`。七建筑、24农田层项和32类装饰均提供四向PNG；灯光固定屏幕左上，必须选对应PNG，不能平面旋转整图。人物 `down/left/up/right` 是屏幕运动方向，与世界q序号没有等价关系。

| q | 包内世界坐标变换 | 选图 |
| --- | --- | --- |
| q0 | `(x,y,z)` | `views` 中 q=0 |
| q1 | `(-y,x,z)` | `views` 中 q=1 |
| q2 | `(-x,-y,z)` | `views` 中 q=2 |
| q3 | `(y,-x,z)` | `views` 中 q=3 |

建筑画布256×240、pivot=(128,176)，农田224×192、pivot=(112,128)。工作中心投影减pivot得到图像左上角，方向不移动接触点。干湿土、播种及作物层同取一个q，生长三档继续读取真实进度。土层固定低层，设施、人物及装饰按接触点排序；选框和冲突格继续读取实际九格几何。

逐方向采用包内实际提供的动效；当前交付包只为q0两建筑和三作物提供动效，q1～q3使用各自完整静态PNG。后续素材增加其他方向动效时按对应朝向接入；本次不补绘或把q0局部层旋转伪造其他方向。其他朝向不能残留q0叶片、烟或风动植株。真实成功结果仍只消费一次，动画不结算经营。

32类装饰从提供的四向资源随机选取；固定独立种子保持可重复，纯环境、实际占地清除与拆除不复生规则不变。此前环境仅使用q0，本次接入其他方向；不新增玩家选择或旋转入口。动效与环境长期说明见[局部动效](../architecture/world/world-map/implementation-bright-motion.md)及[环境装饰](../architecture/world/world-map/implementation-environment-decoration.md)。

## 道路分期

[#143](https://github.com/Fotally/Farm-Exchange/issues/143) 跟踪按实际道路布局判断两种斜向与独立交汇素材的规则。清亮v2的草/土/水81组合图集不包含道路PNG，当前游戏道路由灰色多边形绘制；道路素材配套与复杂连接处理均留在 #143，本单不接入或记为已完成。连接细节由该issue确认，不扩展本次设施旋转命令。
