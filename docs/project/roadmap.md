# 游戏系统规划

已确认玩法的细节按主题记录在[游戏规则](../README.md#游戏规则)；代码模块接口记录在[代码架构](../README.md#代码架构)。本页维护范围、待确认事项和阶段。

## 已确认背景

- 类型：放置挂机游戏。
- 地图：128×128 格。
- 视角：等距视角。
- 引擎：Godot 4.7.2 Mono，安装目录见项目根目录 `AGENTS.md`。
- 脚本语言：C#，使用 Godot Mono。
- 首条挂机循环：开局已有中心农田、加工场地与 3 名真实耕作工人，玩家仍可继续建造；工人按经营秒移动到田、播种和浇水，作物成熟后自动入库，可直接出售原料，或交给对应场地加工后出售加工品。
- 扩张循环：积累足够的钱后在空地建造更多生产建筑。
- 地图固定为单张 128×128，菱形边缘清晰，镜头中心不能移出地图。中心免费预置 3 块农田和 2 处配套加工场地；玩家可在任意空地建造，每座生产建筑暂收 10.00 金币，道路每格 1.00 金币，初始金币为 50.00。左键短按选格、左键拖动平移。1280×720 基准视窗的最远缩放为 1.25 倍，单屏最多出现 682 个完整或部分可见地块。
- 已确认可建造和移除农田。移除时未收获作物消失，不退费用。首版体验重点是放置生产建筑并自动产出。
- 现有七种作物和各自的加工场地。具体时长、收获量及产物见[作物与选种](../gameplay/production/crop-growth.md)。
- 开局三块农田每局等概率选择“三块同种”或“两块同种加一块另一种”；两处加工场地按所选作物匹配。同一种子得到相同开局配置，新游戏随机生成。
- 每秒推进一次经营；7 个游戏日等于 360 秒。第 1 天面粉售价为 5.00 金币，之后每到新日按市场种子和天数从有界曲线直接取价，面粉价格始终在 1.00～20.00 金币之间，单日涨跌不超过 20%。其余加工品按当天面粉价的固定倍率定价；小幅、中幅和大幅是实际涨跌结果的分类。
- 七种原料均可按品种出售公共库存；每种原料当前按对应加工品当日售价的 50% 计价，比例可逐种调整。加工品仍可一次出售全部，已投入加工的原料不可出售。详见[出售与价格](../gameplay/trading/sales.md)。
- 每种原料的公共库存保留底线默认为 0，在库存窗口按非负整数设置；设置本身不触发领取，下一经营步的领取阶段使用新底线。新建加工场地仍按稳定格序即时尝试全场领取；自动加工只取超过底线的部分，手动出售不受底线限制，提高底线不退回已投入原料。详见[加工](../gameplay/production/processing.md)。
- 农田可留存雨水；降雨与工人浇水使用同一供水状态，已获水作物生长中再次遇雨不重置，收获清除本轮水分。改种保水、拆除清水；具体顺序见[农田供水与降雨](../gameplay/production/water-and-rain.md)。当前主场景暂无天气生成。
- 七种作物各有适宜季节；播种前按当前季节、连续适宜区间与预计成熟时刻检查。干田最低预留 1 秒供水，成熟恰在边界先结算；已播种待水或生长中作物进入禁生季节时自动清理本轮作物和水分，保留农田与选种，不增加清理劳动或费用。具体表与口径见[作物与选种](../gameplay/production/crop-growth.md)。
- 工人横纵斜向每秒移动 1 格，走直线穿越占用，不受道路连通影响；播种与浇水各用完整 1 秒，播种后原地浇水。三人共享稳定轮转顺序，每田独占认领，完成或失效释放。两日目标从空田具备条件开始计经过时间；三人和 24 田在同一 8×8 范围内以两日验收，超出范围仍照料但不承诺两日达标；完整规则与预算见[实施方案](../architecture/workers/worker-scheduler/implementation-movement-proposal.md)。
- 道路独占一格、每格 1.00 金币；目录选择后逐格连续点击铺设，Esc 或取消退出。路面灰色，详情可拆除且不退款；当前只影响布局与外观，不进入生产或改变工人速度。规则见[道路铺设与移除](../gameplay/land/roads.md)。

## 系统划分

系统按玩家行为和数据流拆分；已生效规则见[文档导航](../README.md)。

| 模块 | 职责 | 对外接口应保持的形状 |
| --- | --- | --- |
| 经营入口 `FarmGame` | 生成中心开局布局，协调占用、农田、加工、工人、库存、金币与日历；按固定顺序推进经营、换日并处理两类交易 | 聚合格子快照，查询库存价格，接收经营命令并推进一秒 |
| `LandOccupancy`、`PlacementRules`、`PlantingRules`、`FarmingSystem`、`ProcessingSystem`、`WorkerScheduler` | 分别维护每格主要占用、只读放置检查、只读播种检查、农田水分与生命周期、加工批次和三人工人的位置、任务、认领及游标 | 由 `FarmGame` 组合完整建造、拆除和推进；播种执行与详情共用季节判断，降雨和工人共用供水操作；调度算法不泄漏给调用方 |
| `CropCatalog`、`Inventory`、`Wallet` | 分别唯一维护七作物定义、原料与加工品公共库存、金币余额 | `FarmGame` 查询定义并协调生产入库、出售和建造收支 |
| 市场曲线 `MarketPriceCurve` | 按市场种子和天数计算有界面粉价格 | 输入任意有效天数，直接返回以分计价的当天价格 |
| 日历 `GameCalendar` 与比例 `GameTimeUnits` | 唯一维护累计模拟秒与暂停，换算年月日、季节和生产精确时长 | `FarmGame` 每步推进一秒；界面读取季、年、月、日 |
| 地图表现 `WorldMap` | 分块缓存地块与作物绘制结果，绘制边缘，转换等距坐标，选择土地 | 接收游戏状态并在经营变化后同步外观，发出所选格坐标，限制镜头中心在菱形内 |
| 镜头输入 `CameraController` | 区分左键点击与拖动，处理缩放和平移 | 将短按交给地图选择，将镜头位置交给地图限制 |
| 场景协调 `Main` | 持有摆放和所选格，接收窗口意图、驱动计时器、统一刷新 | 将玩家操作转交游戏状态并显示结果 |
| UI 窗口与面板 | `DraggableWindow` 管拖动与边界，各窗口固定控件并只更新值；农田和加工详情使用经营语义快照，道路详情展示用途与移除 | 发出建筑选择、改种、移除和出售意图；位置只在本次运行保留 |
| 存档（后续） | 保存必要状态、恢复进度 | 读写完整游戏状态；离线收益规则待确认 |

`FarmGame` 仍把经营命令和相位顺序收在一个入口：调用方只知道格坐标、命令与经营步进，不需知道内部状态如何分配。各模块唯一持有自己的状态，`FarmGame.GetPlot` 聚合只读快照。价格生成由 `MarketPriceCurve` 独立完成，使任意天数都能直接重算并单独验证长期边界。`WorldMap` 只根据快照绘制和选择，不复制经营规则。只有出现第二种实际实现时才新增适配器。

## 分阶段交付

1. **地图基础（已实现）**：可运行项目、128×128 等距地图、镜头移动与缩放、格子定位。此阶段不预设生产或交易玩法。
2. **最小可玩循环（已实现）**：三名工人自动到田播种浇水，成熟自动收获、对应场地加工、按当前市场价出售，再用收入建造农田和加工场地。
3. **进度持续性**：按已确认规则加入存档、加载与离线收益。
4. **扩展内容（七种作物与配套加工已实现）**：按[作物](../gameplay/production/crop-growth.md)与[交易](../gameplay/trading/sales.md)规则提供独立农田选种、对应加工场地与全部加工品交易；其他建筑、目标与数值平衡待后续确认。

每阶段以引擎可运行、界面能验证当前行为、对应文档已更新为完成条件。存档、离线收益和扩展内容待后续确认。
