# 市场价格曲线调研

## 调研目标

为单机面粉市场选择一条价格曲线。价格需要满足以下约束：

- 存在可配置的最低价 `L` 与最高价 `U`，任意一天的价格都不能越界；
- 曲线连续、每日变化平缓，游戏每 10 tick 推进一天后按天数直接取样；
- 每日涨跌幅由相邻两天价格计算，而不是先抽取“小幅 / 中幅 / 大幅”档位再反推价格；
- 曲线不能过早暴露简单周期；
- 固定种子后可重复，便于自动化测试。

玩法数值现已确认：最低价 `L = 1.00` 金币，最高价 `U = 20.00` 金币，第 1 天初始价为 `5.00` 金币，每 10 tick 经过 1 天。

## 资料结论

Godot 官方将随机噪声用于“输入为位置、时间或其他量时，取得缓慢变化的值”，并提供了 `FastNoiseLite` 的一维 C# 示例；示例使用 `SimplexSmooth`、种子、4 个 octave 和 `1 / 20` 的 frequency，逐点打印缓慢变化的序列。因此，把“天数”作为一维坐标直接取样符合引擎原生用途。[Godot：Random noise](https://docs.godotengine.org/en/stable/tutorials/math/random_number_generation.html#random-noise)

`FastNoiseLite` 内置 Value、Perlin、Cellular、Simplex 等算法；`frequency` 越低，结果越平滑，`seed` 控制噪声种子。Godot 同时明确提醒：多数噪声值位于 `[-1, 1]`，但并非所有配置都严格如此，部分 Cellular 配置可能超过 `1`。因此，即使选用 `SimplexSmooth`，游戏规则仍应在公式入口显式钳制噪声值，不能把价格硬边界建立在“通常不会越界”上。[Godot：FastNoiseLite](https://docs.godotengine.org/en/stable/classes/class_fastnoiselite.html)

`Noise.GetNoise1D(x)` 是只读取给定一维坐标值的接口，不修改实例成员。这使同一种子、同一配置下的价格可以由“天数”直接定位，不需要从第 1 天逐日重放。[Godot：Noise.get_noise_1d](https://docs.godotengine.org/en/stable/classes/class_noise.html#class-noise-method-get-noise-1d)

正弦函数具有明确周期，且导数有解析形式。由此可以同时推导叠加曲线的值域和相邻整数日的最大变化量；这两项都是仅调低噪声 frequency 无法从 Godot 公共文档得到的硬保证。[NIST DLMF：正弦周期](https://dlmf.nist.gov/4.14#E8)、[NIST DLMF：正弦导数](https://dlmf.nist.gov/4.20#E1)

Ornstein–Uhlenbeck（OU）过程来自 Uhlenbeck 与 Ornstein 对布朗运动的工作，原论文明确讨论了高斯分布。[APS 原论文](https://journals.aps.org/pr/abstract/10.1103/PhysRev.36.823) 高斯分布的取值范围是负无穷到正无穷，因此普通 OU 过程虽有均值回归性质，却天然没有硬性最低价和最高价；仍需截断、反射边界或非线性映射。[NIST：Normal Distribution](https://www.itl.nist.gov/div898/handbook/eda/section3/eda3661.htm)

## 候选方案比较

| 方案 | 硬价格边界 | 周期感 | 单日幅度控制 | 按任意天直接取样 | 当前项目适配性 |
| --- | --- | --- | --- | --- | --- |
| 单条正弦 | 可由振幅直接保证 | 很明显 | 可解析保证 | 可以 | 最简单，但很快会被玩家识破 |
| 多正弦叠加 | 各项绝对振幅和不超过 1 即可保证 | 使用相差较大的周期后不易察觉，最终仍会重复 | 可解析保证 | 可以 | 简单、严格、易测 |
| OU 均值回归过程 | 普通 OU 不保证；截断会贴边，反射或有界变体会增加实现复杂度 | 无固定周期 | 需处理随机增量及边界 | 状态依赖，通常需从前一天递推 | 不适合本次“小而直接”的需求 |
| 单独使用 FastNoiseLite | 显式 `Clamp` 后可保证 | 不呈简单正弦周期 | frequency 可调观感，但官方接口没有给出任意相邻点差值的上界 | 可以 | 引擎原生且自然，但不能独自承担 20% 硬上限 |
| 多正弦 + 小权重 FastNoiseLite | 可解析保证 | 噪声打散叠加正弦的规则感 | 可解析保证，且不依赖噪声斜率 | 可以 | **推荐**：约束明确，代码量仍小 |

“有界噪声”有两种含义，需要区分：

1. **输出值有界**：将噪声显式钳制到 `[-1, 1]` 后可以保证价格不越过 `L` 与 `U`。
2. **相邻样本差有界且足够小**：任何两个 `[-1, 1]` 值的差最多为 `2`，但这一粗上界通常不足以保证每日涨跌不超过 20%。降低 frequency 能改善实际观感，不能替代硬规则的数学约束。

## 推荐模型：多周期正弦基线叠加小权重平滑噪声

设天数为整数 `d >= 1`，先定义归一化曲线：

```text
n(d) = Clamp(FastNoiseLite(seed).GetNoise1D(d), -1, 1)

q(d) = Σ[aᵢ × sin(2πd / Tᵢ + φᵢ)] + aₙ × n(d)
```

其中：

- `Tᵢ` 是相差较大的周期，避免短期内同步重复；
- `φᵢ` 是由市场种子一次性生成的相位；
- `aᵢ` 是各周期权重，`aₙ` 是噪声权重；
- 约束 `Σ|aᵢ| + |aₙ| <= 1`。

通用方案可把归一化曲线线性映射到价格区间：

```text
M = (L + U) / 2
H = (U - L) / 2
P(d) = M + H × q(d)
```

因为每个正弦项与钳制后的噪声都在 `[-1, 1]`，且权重绝对值之和不超过 `1`，所以 `q(d)` 必在 `[-1, 1]`，从而严格得到：

```text
L <= P(d) <= U
```

每日涨跌幅直接由相邻价格计算：

```text
R(d) = P(d) / P(d - 1) - 1
```

显示档位只是对 `|R(d)|` 的分类，不再参与生成：

- 小幅：`0% <= |R| < 5%`
- 中幅：`5% <= |R| < 15%`
- 大幅：`15% <= |R| <= 20%`

### 如何严格限制单日涨跌不超过 20%

相邻两个整数日之间，单个正弦项的最大差为 `2|aᵢ|sin(π / Tᵢ)`；钳制噪声的任意相邻值之差最多为 `2`。因此归一化曲线的最大日差为：

```text
Dmax = Σ[2|aᵢ|sin(π / Tᵢ)] + 2|aₙ|
```

价格的分母最小为 `L`，所以每日相对涨跌的硬上界为：

```text
|R(d)| <= H × Dmax / L
```

若目标上限为 `rmax = 0.20`，参数必须满足：

```text
Dmax <= 2 × rmax × L / (U - L)
```

这条约束同时说明了为何最低价、最高价必须先由用户确认：价格区间越宽且最低价越低，同一条归一化曲线换算出的相对涨跌就越大。不能先拍定周期和权重，再声称它适用于任何价格上下界。

### 参数选择原则

- 使用 3 个周期已经足够；短、中、长周期各一个，不继续增加层数。
- 周期取相差明显、没有短公倍数的整数，例如 `17、61、223` 天，理论组合重复期很长，短期不呈单一周期。
- 长周期权重最大，短周期权重较小，让趋势缓慢而不是每天锯齿跳动。
- `FastNoiseLite` 使用 `SimplexSmooth`，frequency 先以官方示例的 `1 / 20` 为调参起点；噪声权重保持很小，它只负责打散规律感，不负责主要波动。
- 相位和噪声 seed 固定后，`P(d)` 是天数的纯函数；新游戏可随机生成市场种子，测试使用固定种子。
- 具体权重必须在 `L`、`U` 确认后代入上式计算。举例时可以试算，但不应把未经确认的上下界写死为玩法规则。

这套叠加不是“超限后再把涨跌幅截成 20%”。后者会让当天价格依赖前一天的截断结果，破坏“从曲线上按天直接取样”；推荐模型是在参数阶段就保证整条曲线符合边界。

## 关于“概率限制”的说明

改为曲线取样后，小幅、中幅、大幅不再是三个互斥抽奖事件，因此不存在运行时的 `70% / 25% / 5%` 档位概率。它们是对生成结果的统计标签。

如果后续仍要求某个精确档位占比，就需要在固定统计窗口内调参，或重新引入按档位抽样；前者只能得到近似频率，后者与当前“先有曲线、再算涨跌幅”的方向冲突。当前版本应只承诺：价格不越界、每日不超过 20%、曲线平滑且固定种子可复现。各档位的长期占比作为平衡数据观察，不先写成硬规则。

## 建议的自动化验收

实现阶段至少覆盖以下测试：

1. **时间规则**：第 1 天为初始显示；每推进 10 tick 天数加 1，并从新天数重新取价。
2. **边界**：固定多个种子，抽样足够长的天数区间，所有价格均满足 `L <= P(d) <= U`；此外直接测试公式的权重约束。
3. **单日幅度**：先用参数公式断言理论上界不超过 20%，再对长序列逐日验证 `|R(d)| <= 20%`。
4. **可复现**：相同 seed、相同天数得到完全一致的价格；不同顺序查询天数也得到相同结果。
5. **档位边界**：分别检查 `5%` 与 `15%` 落入哪一档，避免显示文案重叠。
6. **交易结算**：出售收入使用当天价格；跨日后旧库存按新一天价格出售。
7. **界面**：面板显示当前天数、当前售价以及相对前一天的涨跌百分比。

价格出现小数后，经营结算宜使用“分”为整数单位，再格式化成两位小数，避免二进制浮点误差进入库存与金币规则。这属于实现数据类型选择，不改变曲线公式。

## 最终建议

采用“3 个不同周期的正弦项 + 1 个极小权重的 `FastNoiseLite SimplexSmooth` 项”。它比单正弦更难看出周期，比 OU 和有界随机微分过程更容易按天直接查询，也比单独使用 FastNoiseLite 更容易对价格边界和每日 20% 上限作出硬保证。

## 已采用的 1.00～20.00 参数化方案

由于已确认价格跨度达到 20 倍，实际实现将线性映射改为对数映射：

```text
P(d) = L × (U / L)^((q(d) + 1) / 2)
```

这样 `q = -1` 时价格为 `L`，`q = 1` 时价格为 `U`，并且相同的曲线日差在低价和高价区间产生一致的价格倍率。实现采用以下参数：

| 分量 | 权重 | 周期 |
| --- | ---: | ---: |
| 长周期正弦 | 0.58 | 180 天 |
| 中周期正弦 | 0.28 | 61 天 |
| 短周期正弦 | 0.12 | 16 天 |
| 平滑噪声 | 0.02 | frequency 0.05 |

正弦权重与噪声权重合计为 1。市场种子随机生成中、短周期相位，再反求满足初始价格的长周期相位，因此不同新游戏具有不同走势且第 1 天仍精确落在 5.00 金币。噪声减去第 1 天样本后再除以 2，因此不改变初始价且该项仍严格处于 `[-1, 1]`。价格以分为单位四舍五入；权重公式本身保证结果处于已确认的绝对边界内，不依赖最终兜底截断。

对数映射下，未取整价格的最大单日倍率由下式约束：

```text
P(d) / P(d - 1) <= (U / L)^(Dmax / 2)
```

代入当前周期和权重，保守的归一化最大日差约为 `0.1159`，对应未取整价格的理论最大涨幅约 `19.0%`，并为按分取整留出余量。自动化测试另对固定种子的 10 万天序列逐日验证，确认价格边界、20% 上限以及三种涨跌分类均实际成立。
