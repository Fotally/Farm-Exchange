# 清亮完整 v2 使用基准

本页维护当前素材使用边界。来源包版本、ZIP SHA-256 与授权历史见[素材来源](../project/asset-sources.md#清亮完整-v2来源与授权历史)；各组实际采用状态、路径映射、方向和导入约定由[当前接入入口](../project/asset-sources.md#当前接入入口)直接连接所属 `source_notes.md`，不在本页复制资源数量或实施阶段表。

2026-10-06 的包内容检查、v1/v2 比对及 2026-10-07 首批接入经过已按原语境保存为[历史分析](../archive/research/bright-complete-v2.md)。历史检查及验收不代替后续版本的运行验收；来源包自己的验证结果也不等于主项目验收。

## 当前使用约束

- 正式资源按[assets 目录约定](../project/asset-organization.md)归入游戏用途目录；包内各独立工程有自己的 `res://` 根，原 ZIP、示例工程及重建输入不作为主游戏依赖。包内 `docs/REPOSITORY_HANDOFF.md` 的议题描述是交付背景，不能替代仓库现行规则。
- 水域表现已经接入。地形的 mask、水纹与逻辑岸线分别履行所属职责，不从 PNG 颜色推导建造或通行；当前资源见[地形来源](../../assets/gameplay/terrain/source_notes.md)，经营与导航契约见[地形 Interface](../architecture/terrain/interface-terrain-map.md)。
- 农田、作物、建筑和环境装饰已使用四向静态资源。世界朝向与人物的屏幕移动方向、地形纹理变体分别处理；不能将整图二维旋转来伪造朝向。具体选图、画布与 pivot 由各目录来源说明维护，建前操作见[建造规则](../gameplay/land/opening-and-building.md)。
- 建筑活动部件与根点植株动效仍仅覆盖 q0，其他朝向使用对应静态图；不能将“完整清亮”理解成全部设施和作物均有四向动效。动效底图替换相应静态层，避免双份叶片或作物；收获／加工成功短效果与该 q0 替换范围分开，按真实结果消费。详细范围见[局部动效说明](../architecture/world/world-map/implementation-bright-motion.md)及其来源链接。
- 人物采用合成动作帧，不重复叠加同一工具或水滴；动画时长、单次／循环与脚根约定见[NPC 来源](../../assets/gameplay/npc/source_notes.md)。动画只展示实际位置和有效成功结果，不决定播种、供水、收获或加工结算。
- UI 的加工与道路缩略复用正式素材，农田与选种保留 SVG；UI 裁取和派生缓存不改写世界 PNG 或地图 pivot。具体加载与历史 SVG 状态见[UI 来源](../../assets/ui/source_notes.md)。
- 可选 atlas 属于包内纹理组织方式，不要求新增全项目素材注册器、动态扫描器或通用加载框架。新素材只按已确认范围接入，不扩展经营规则或授权。

## 尚未接入与待确认事项

- **采收搬运**：没有因整包提供 `harvest`、`carry_idle`、`carry_walk` 而启用工人采收或运输；现行成熟自动入公共库存。任务、容量、目的地与作物工具等仍由[#112 提案](../project/worker-harvest-transport-proposal.md)确认。
- **加工岗位**：`process` 动作未启用为主经营岗位；当前场地自动领取和完成批次，建筑活动部件不等于工人加工。岗位规则、站位和动作适配仍见[#113 提案](../project/worker-processing-proposal.md)。
- **四季素材**：季节经营规则与四季美术是不同范围；现有世界加载路径不按季节切换地形、设施、作物或装饰纹理，未实现四季素材接入。不能由年度表、适季作物或完整包名称推断四季画面已交付。
- **其他动效与未采用包内容**：未提供或未接入的方向、设施动效和道路扩展细节不自行补绘；按各目录来源说明和关联议题确定后续范围。预览字体子集不自动替换正式游戏字体，只引入实际采用文件及对应许可证。

本页没有重新执行图形、性能、引擎导入或平台导出验收；对应版本证据按[构建与验收](../project/build-and-validation.md)记录，历史首批结果仅保留在归档中。
