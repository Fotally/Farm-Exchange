# 游戏系统规划

## 已确认背景

- 类型：放置挂机游戏。
- 地图：128×128 格。
- 视角：等距视角。
- 引擎：Godot 4.7.2 Mono，安装目录见项目根目录 `AGENTS.md`。
- 脚本语言：C#，使用 Godot Mono。
- 首条挂机循环：玩家建造农田；开局 1 名工人每 tick 自动完成 1 次播种或浇水，照料所有已建农田；小麦成熟后须经磨坊加工成面粉才能出售。
- 扩张循环：积累足够的钱后解锁更多土地。
- 地图固定为单张 128×128，菱形边缘清晰，镜头中心不能移出地图。玩家可从任意位置选择土地；开局有 2 次免费选地机会。左键短按选格、左键拖动平移。1280×720 基准视窗的最远缩放为 1.25 倍，单屏最多出现 682 个完整或部分可见地块。
- 已确认可建造和移除农田。移除时未收获作物消失，不退费用。首版体验重点是放置生产建筑并自动产出。
- 首版只有小麦作物。磨坊建在已解锁空地上，建造和移除免费；每座磨坊自动从公共库存取 1 份小麦，10 tick 后产出 1 份面粉，并继续处理下一份。移除加工中的磨坊时，已投入的小麦消失。加工不消耗金币，只有面粉能出售。
- 每 10 tick 经过 1 天。第 1 天面粉售价为 5.00 金币，之后按市场种子和天数从有界曲线直接取价，价格始终在 1.00～20.00 金币之间，单日涨跌不超过 20%。小幅、中幅和大幅是实际涨跌结果的分类，不再按概率抽取。

## 待用户确认

- 后续建筑类型与建造规则。
- 存档与离线收益规则。

## 系统划分

系统按玩家行为和数据流拆分；首版规则见 `生产与交易.md`。

| 模块 | 职责 | 对外接口应保持的形状 |
| --- | --- | --- |
| 游戏状态 `FarmGame` | 持有 128×128 土地、单工人轮流播种浇水、作物、库存、金币与天数；按 tick 收获、换日并处理交易 | 查询格子快照，接收明确的经营命令，推进一次 tick |
| 市场曲线 `MarketPriceCurve` | 按市场种子和天数计算有界面粉价格 | 输入任意有效天数，直接返回以分计价的当天价格 |
| 地图表现 `WorldMap` | 绘制可见格子及边缘，转换等距坐标，选择土地 | 接收游戏状态，发出所选格坐标，限制镜头中心在菱形内 |
| 镜头输入 `CameraController` | 区分左键点击与拖动，处理缩放和平移 | 将短按交给地图选择，将镜头位置交给地图限制 |
| 场景协调 `Main` | 接收按钮操作、驱动计时器、刷新界面 | 将玩家操作转交游戏状态并显示结果 |
| 存档（后续） | 保存必要状态、恢复进度 | 读写完整游戏状态；离线收益规则待确认 |

`FarmGame` 把生产、库存、交易、换日和解锁收在同一模块里：调用方只知道格坐标、经营命令与 tick，不需知道遍历或资源更新顺序。价格生成由 `MarketPriceCurve` 独立完成，使任意天数都能直接重算并单独验证长期边界。`WorldMap` 只根据快照绘制和选择，不复制经营规则。只有出现第二种实际实现时才新增适配器。

## 分阶段交付

1. **地图基础（已实现）**：可运行项目、128×128 等距地图、镜头移动与缩放、格子定位。此阶段不预设生产或交易玩法。
2. **最小可玩循环（已实现）**：单工人自动播种浇水，按 tick 收获小麦、磨坊加工面粉、按每日市场价出售面粉、用收入解锁土地；界面展示所选土地、天数、售价、涨跌、库存与金钱。
3. **进度持续性**：按已确认规则加入存档、加载与离线收益。
4. **扩展内容**：在最小循环可玩后增加建筑、资源、目标与数值平衡。

每阶段以引擎可运行、界面能验证当前行为、对应文档已更新为完成条件。存档、离线收益和扩展内容待后续确认。
