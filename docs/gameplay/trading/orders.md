# 委托挂单与持续买卖策略

玩家在“委托策略”窗口选择十四商品之一、买卖方向、一次委托或持续策略，配置触发条件、数量和现金保留。单据只针对一种商品；市场按[正式报价](market-quotes.md)运行，不因条件增加额外收益。

## 条件与数量

条件支持当前商品价格（分）、公共库存总量（含冻结）和当前季节。价格、库存支持小于、小于等于、等于、大于等于、大于；季节仅支持等于春、夏、秋、冬。同组“同时满足”，不同组“或”；多个组成立也只成交一次。库存积压不强制出售，价格不满意可以继续等。

数量与条件分别设置：固定数量；买入补到目标库存；卖出减到目标剩余库存。一次目标单在创建时计算当时总库存差额并锁定数量，之后库存变化不重算；只编辑价格、条件或现金保留也不重算。主动修改商品、买卖方向、数量模式或目标数量，或切换执行频次、预算模式形成新的数量意图时，按新设置重新确定数量并完整检查；失败保留原单和冻结。持续策略每次检查按当前总库存重新计算。一次目标差额必须为正，持续单达到目标后等待。不缩减成交数量绕过资源或容量检查。

## 一次单冻结

一次买单选择下列方式之一：

| 方式 | 冻结和成交 |
| --- | --- |
| 固定总预算 | 冻结完整预算，预算包含手续费。成交时按执行价计算预算内可买的最大整数数量，一次完整成交；预算不足一份时等待。未用预算释放。 |
| 最高买价与数量 | 冻结最高买价乘已确定数量，再加该总额的手续费；实际报价超过最高价时等待。较低报价按实际价格收费，剩余冻结额度释放。 |

一次卖单冻结确定数量。冻结不转移或复制余额与库存：总量仍含冻结，可用量等于总量减冻结。其他挂单、即时交易、建造和加工只能使用可用资源。全部出售仅出售可用商品；撤销释放本单额度，编辑可使用本单原额度，但不能使用其他单冻结资源。

持续策略不冻结资金或商品，只在执行时检查资源。买入、卖出均不部分成交，资金、库存、容量、现金保留不满足时完整等待，不修改金币、库存、冻结或收费。

## 现金保留与费用

每张买单支持固定保留金额，或按原设单现金比例保留。现金基准是建单时总余额，比例为 0～100 的整数百分比；按基准乘比例向上取整到分，一次锁定。以后现金和库存变化、编辑价格或条件都不重算基准；修改保留参数仍使用原基准，新建单才取新基准。

一次买单冻结后可用现金不得低于保留金额。真实买入含费后，可用现金也不得低于保留金额，不能把其他单冻结资金当作保留现金。持续单执行时遵守同一检查。保留限制自动买入，玩家仍可主动消费；低于保留线时自动买入等待，不强制出售。

| 数值 | 生效规则 |
| --- | --- |
| 委托买入手续费 | 实际成交货值的 1%，向上取整到分，加入支出。 |
| 委托卖出手续费 | 实际成交货值的 1%，向上取整到分，从收入扣除。 |
| 未成交、撤销、编辑 | 不收费。 |
| 即时买卖和全部出售 | 继续零费，见[即时交易](sales.md)。 |

例如货值 0.25 金币，手续费为 0.01；买入支出 0.26，卖出入账 0.24。界面分别显示最近真实成交的商品、买卖方向、实际数量、货值、费用和成交后余额；货值不含手续费。编辑商品或方向后，最近成交仍保持成交当时的身份和结果，下一次成功成交才替换。

## 执行、编辑与暂停

每个未暂停经营秒完成生产、加工领取、工人动作、日历及行情更新后，按原建单顺序检查。每单该秒最多成交一次，后单读取前单成交后的真实资源。提交或查询本身不执行；自动买入原料已错过本秒领取，下一经营秒才可加工，随后主动新建加工场地仍遵守既有即时全场领取规则。

一次单成功后结束，持续单成功后保留到停用或撤销。编辑以同 ID 整体替换和重验，失败保留原配置、冻结、现金基准和最近成交。持续策略可以启用、停用；一次单只能编辑或撤销。成功及撤销记录仍可查看，终态不能再次编辑或成交。

暂停允许创建、查看、编辑、启停持续策略及撤销，但不自动执行。当前没有存档，关闭后不补算现实时间。季节条件仅读取日历，不改变报价公式；深入季节经济规则另见 [#80](https://github.com/Fotally/Farm-Exchange/issues/80)。
