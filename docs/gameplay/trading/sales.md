# 公共库存与即时交易

每种作物分别有原料和加工品公共库存，合计十四种商品。生产入库、买入、加工领取和卖出共用这些库存，不另设市场持仓。商品初价、独立行情公式、节日报价日期及消息以[商品行情](market-quotes.md)为准。

十四种商品均可按执行时生效报价买入和卖出，买卖同价、不收手续费。选中一种商品后输入 1～`int.MaxValue` 的整数数量，可买入、卖出指定数量或卖出该商品全部；保留按品种出售全部原料、一次出售全部成品快捷操作。旧库存也按当前价结算，不使用买入成本或收获当天价格。金币以整数分保存，显示两位小数。

资金不足、公共库存不足、商品库存不能容纳买入数量或金币余额不能容纳全部收入时正常拒绝；金币和所有库存零修改，不会只卖出部分成品。每种库存及金币余额上限均为 `int.MaxValue`，累计数量与金额先以长整数计算再检查。全售空库存成功返回零；主动输入零或负数则拒绝。[一次委托](orders.md)冻结的金币和商品仍计入总量，但不能用于即时交易、建造或加工；本页的可出售库存与可支用现金只指未冻结部分，全部出售也仅出售可用部分。

买入原料进入公共库存，操作本身不启动加工。下一经营步的领取阶段按逐种保留底线和稳定格序自动领取；随后新建加工场地仍会立即执行既有全场领取路径。保留底线只约束自动加工，手动卖出可消耗保留部分，不清除底线。已投入加工的原料不再计入可售库存。底线与领取规则见[原料加工](../production/processing.md)。

暂停时仍可主动交易与修改底线，日历、行情和生产均保持。市场展示十四商品当前报价、上次报价、实际涨跌和库存，并显示本次、下一次实际报价日期及已公布消息。刷新保留所选商品、数量草稿、输入焦点与光标；点击执行时重新使用已生效报价。

交易命令见[FarmGame 接口](../../architecture/game-state/farm-game/interface-farm-game.md)，完整结算见[TradingService 接口](../../architecture/trading/trading-service/interface-trading-service.md)。`tests/unit/TestTradingService.cs` 验证收支守恒、失败零修改、全售完整性、当前价、暂停交易与买入领取时点；主场景交易由端到端测试验收。
