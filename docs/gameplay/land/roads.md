# 道路铺设与移除

对应 [issue #45](https://github.com/Fotally/Farm-Exchange/issues/45)。当前道路用于地图布局与视觉表现，不影响生产、移动速度、碰撞或工人的播种供水节奏。

## 铺设与费用

在建造目录选择道路后，逐格点击地图空位连续铺设，每格费用为 1.00 金币。成功后保持道路摆放模式；按 Esc 或点击取消退出。每次实际执行都重新检查范围、占用和余额，重复铺设、越界、已有建筑或金币不足时拒绝，不扣费、不覆盖原对象。费用统一由 `FarmGame.GetBuildingCostCents` 查询，目录、提示和实际命令使用同一规则。

道路独占一格，与农田和加工场地互斥；道路格不能叠加第二条道路或生产建筑。路面为灰色，使用现有地图块网格；选中道路时显示道路详情，可点击移除。移除立即释放占用，恢复绿色空地，不退费用。占用与建造通用规则见[开局与建造](opening-and-building.md)。

## 与经营的关系

道路不创建农田、加工批次、水分或作物状态，不参与生产推进，也不触发空闲加工场地领取原料。工人仍按已确认的格距离与经营秒直线移动，可穿越占用；无路、有路、断路均可正常播种和浇水。本批不提供速度加成，不增加道路连接判断或寻路。工人规则见[移动与多人调度](../../architecture/workers/worker-scheduler/implementation-movement-proposal.md)。

土地信息仍由 `LandOccupancy` 唯一维护，其他模块通过只读查询获取占用；移动耗时仍封装在 `WorkerScheduler` 内部。将来确认道路影响速度等属性时，可在这两个实际位置接入规则；当前不添加恒定倍率 Module，不把速度计算交给 UI 或动画，也不猜测未来倍率。

## 验收对应

- 经营与土地测试验证费用预检、执行重验、占用互斥、失败零修改、移除不退款以及道路没有生产状态。
- 主场景端到端测试验证目录费用、连续逐格铺设、取消、显式道路详情及拆除。
- 道路地图集成测试验证灰色实际像素、独立选框、跨块外观同步、拆除恢复空地且不影响相邻道路；有窗口运行保存前后截图。
- 工人回归验证无路、有路和断路的到达与生产不变；地图性能继续按既有门槛验收。
