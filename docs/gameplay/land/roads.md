# 道路铺设与移除

道路只能占完整陆地格，含水岸格不能铺路；新建整段只要一格含水就全部拒绝，金币和原道路均不改变。道路不跨水形成桥，也不改变工人速度；工人通过地形真实岸线寻路，不以道路连接作为通行条件。

道路独占一个 64×32 世界像素基础格，与农田和加工场地的任意占用子格互斥。土路、碎石、卵石、红砖、石板五种材质均为每格 1.00 金币，材质只改变外观，选路优先程度相同。工人通过 Godot 原生区域成本尽量沿道路行走：道路成本为 1，普通陆地为 2；实际移动速度仍为每经营秒 3 基础格。道路不是通行前提，断路或没有道路也能在可通行陆地工作；原生 A*／Funnel 提供尽力偏好，不保证吸附每段近路或得到所有加权距离的全局最优路线。

## 成段新建

在建造目录的道路分类选择材质后，无需点击，鼠标所在地图格就显示该材质的单格道路与占地预览；移动鼠标持续更新，实际占用／越界标红、可用资金不足提示每格费用与可用金币，相邻旧路显示连接后的形状。此时尚未设定手势起点，也不记录铺路轨迹，不登记土地、不扣费。第一次左键短按才锁定起点；继续移动更新本段终点，第二次短按尝试提交整段。起终点包含在候选格中；同轴为直线，双轴为一个转弯的 L 形，不自动绕障碍。

L 形按本段鼠标首先明确移动的网格轴锁定顺序。例如先往屏幕左上移动，再往右下移动，就按相同次序连接，不以最终起终点替换顺序。首次移动的两轴格位移相等时暂不锁轴；双轴终点尚未明确顺序时，第二次点击提示“请先沿一条网格轴移动，确定转弯顺序”，保留本段供调整。直线与单格不需要预先锁轴。鼠标按住期间不采集铺路轨迹，左键始终保留拖镜头用途。

提交时经营入口重新检查全部候选格、地图范围和可用金币；转角只计一次，总费用等于实际候选格数乘以道路单格费用。冻结金币不能用于铺路。已有道路、农田、加工场地均阻挡新建，不能覆盖、替换材质、自动跳过或免费复用旧路。重铺同格需要先拆除。占用或越界格标红；资金不足标红总费用并显示可用金额。第二次点击仍尝试提交并明确报告失败；失败整段不建、不扣费、不清除环境装饰，保留起点、顺序与预览，不留下部分道路。

## 直线拆除

建造目录提供“拆除道路”工具。选中后无需点击，立即预览鼠标所在单格的拆除效果：只有实际道路显示红色半透明待拆标记，邻接道路显示移除此格后的连接形状；空格、农田和加工场地不标成待拆道路。这个预览不设置手势起点、不记录拆除轴，也不修改经营资源。

第一次短按才锁定起点，随后移动预览、第二次短按终点提交。按真实鼠标移动相对起点的主要网格轴选择直线，终点投影到该轴，不要求鼠标精确共线，也不生成 L 形；相等位移保留已有选择。只有实际待拆道路显示红色半透明标记，提示待拆道路格数。

范围可跨空格、农田和加工场地，也可包含不连续、不同材质道路；只移除范围内实际道路，不修改其他设施，不退款。范围没有道路时提示“没有可拆除的道路”并保留当前段；越界整段拒绝。退出工具后点击道路仍可打开独立详情，读取实际材质并拆除这一格。生产设施拆除继续一次释放整座九格，不能通过拆路工具移除。

## 连接与预览

正式道路按四邻格道路存在性自动选择孤立、端点、两种斜向直路、转角、丁字和十字外观；不同材质相邻也连接，没有手动旋转。每格纹理变体稳定选择，预览与建成后保持一致。

新建预览用“正式道路 + 当前空间有效候选道路”计算连接，候选内部连接，受影响旧路临时显示建成后的形状并保留材质；实际冲突格不能当作新路覆盖。拆除预览用“正式道路 − 当前待拆道路”计算保留道路的断开形状。预览使用真实半透明道路纹理和空间标记，不修改正式占用、材质、金币、设施或装饰；移动、隐藏和取消解除旧范围临时外观，跨缓存块的相邻道路同样刷新。材质边界、门前入口、中心磨损和散石仍待确认，不默认启用。

## 镜头与取消

左键或中键拖动仍平移镜头；拖动时隐藏预览，保留本段，松开不提交。镜头拖动位移不纳入轨迹，也不改已锁定 L 形顺序；松开后按当前鼠标格更新终点，下一次真实未按住鼠标的地图移动才可确定轴。缩放、窗口变化和键盘平移只更新终点，不代替鼠标轨迹。界面遮挡、离开窗口及跨界面按下／松开继续防穿透，回到地图恢复预览。

有未提交段时右键或 Esc 先取消当前段、回到选起点状态；没有当前段时退出工具。取消按钮直接退出工具。成功提交或仅取消当前段都清空本段起终点、轨迹及顺序，保留工具与材质；新建和拆路工具均恢复跟随鼠标的单格预览，下一段重新短按选起点，不自动沿用上一终点。鼠标处若刚建成道路，新建工具按真实占用显示冲突，移到空格恢复有效预览；拆路工具刚拆完的空格不显示待拆标记。界面遮挡、拖镜头和离窗也隐藏未点击的单格预览，回到地图恢复。打开大地图会直接退出工具并丢弃未完成道路段，关闭地图不恢复工具。正式道路仍是单格实例，不保存段归属或铺设历史。暂停时仍可预览、新建和拆路，工具不改变暂停状态。农田与加工场地沿用原建造、R 旋转和拆除操作，见[开局与建造](opening-and-building.md)。

## 与经营的关系

道路不创建农田、加工批次、水分或作物状态，不参与生产推进，也不触发空闲加工场地领取原料。工人按真实陆地折线路线与经营秒移动，可穿越建筑占用；无路、有路、断路均可正常播种和浇水。道路不提供速度加成；选路偏好可能改变行程及到田时刻。

成功建拆先原子提交费用与土地，再异步同步最新道路成本。准备期间窗口、镜头、预览和继续建拆保持响应，经营暂候；不会消费经营秒或积累准备期间的追赶时间，不改变玩家原倍率与暂停意图。失败建拆不触发导航准备。新领取或重新规划的任务使用最新已同步道路；已领取任务保留其原始路线和进度，继续到本次任务结束，不因建拆道路瞬移或重新起步。准备期间的连续建拆会合并处理，只有最终道路状态已同步才恢复经营。工人规则见[移动与多人调度](../../architecture/workers/worker-scheduler/implementation-movement-proposal.md)。

土地信息由 `LandOccupancy` 唯一维护，其他模块通过只读查询获取占用；移动耗时封装在 `WorkerScheduler` 内部。
