# 道路铺设与移除

道路占一个 64×32 世界像素的基础格，农田与加工场地各占 3×3（192×96）；因此道路面积为标准生产设施的 1/9。道路用于布局与视觉，不影响生产、移动速度、碰撞或播种供水节奏。

## 铺设与费用

在建造目录选择道路后，鼠标悬停显示自身占地属性对应的预览，逐次点击地图空位连续铺设，当前每格费用为 1.00 金币。每次短按只铺设一份占地，成功后保持道路摆放模式；右键、Esc 或取消按钮统一退出。成功后不弹出详情，退出摆放再点击道路查看详情。每次实际执行都重新检查范围、占用和可用金币，重复铺设、越界、已有建筑或金币不足时拒绝，不扣费、不覆盖原对象。费用统一由 `FarmGame.GetBuildingCostCents` 查询，目录、提示和实际命令使用同一规则；冻结金币不能用于铺路。无效位置仍显示标准费用。

道路与其他建筑共用预览流程：冲突或越界格标红，空间可用格淡绿；金币不足只标红费用并显示可用金额。界面遮挡、离开窗口和拖镜头时隐藏预览，不穿透建造，回到地图恢复。暂停时仍可预览和逐次铺路。完整交互见[开局与建造](opening-and-building.md)。

道路独占一个基础格，与农田或加工场地的任意子格互斥；道路格不能叠加第二条道路或生产设施。路面灰色，使用现有地图块网格；选中后显示独立道路详情，可拆除这一格，恢复空地且不退款。生产设施拆除则一次释放九格，不能局部拆一格。通用规则见[开局与建造](opening-and-building.md)。

## 与经营的关系

道路不创建农田、加工批次、水分或作物状态，不参与生产推进，也不触发空闲加工场地领取原料。工人按格距离与经营秒直线移动，可穿越占用；无路、有路、断路均可正常播种和浇水。道路不提供速度加成，也不参与连接判断或寻路。工人规则见[移动与多人调度](../../architecture/workers/worker-scheduler/implementation-movement-proposal.md)。

土地信息由 `LandOccupancy` 唯一维护，其他模块通过只读查询获取占用；移动耗时封装在 `WorkerScheduler` 内部。
