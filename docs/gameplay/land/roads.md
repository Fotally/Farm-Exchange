# 道路铺设与移除

道路独占一个 64×32 世界像素基础格，与农田和加工场地的任意占用子格互斥。土路、碎石、卵石、红砖、石板五种材质均为每格 1.00 金币，只改变外观。道路用于布局与视觉，不影响生产、工人速度、通行或播种供水节奏。

## 成段新建

在建造目录的道路分类选择材质后，无需点击，鼠标所在地图格就显示该材质的单格道路与占地预览；移动鼠标持续更新，实际占用／越界标红、可用资金不足提示每格费用与可用金币，相邻旧路显示连接后的形状。此时尚未设定手势起点，也不记录铺路轨迹，不登记土地、不扣费。第一次左键短按才锁定起点；继续移动更新本段终点，第二次短按尝试提交整段。起终点包含在候选格中；同轴为直线，双轴为一个转弯的 L 形，不自动绕障碍。

L 形按本段鼠标首先明确移动的网格轴锁定顺序。例如先往屏幕左上移动，再往右下移动，就按相同次序连接，不以最终起终点替换顺序。首次移动的两轴格位移相等时暂不锁轴；双轴终点尚未明确顺序时，第二次点击提示“请先沿一条网格轴移动，确定转弯顺序”，保留本段供调整。直线与单格不需要预先锁轴。鼠标按住期间不采集铺路轨迹，左键始终保留拖镜头用途。

提交时经营入口重新检查全部候选格、地图范围和可用金币；转角只计一次，总费用等于实际候选格数乘以道路单格费用。冻结金币不能用于铺路。已有道路、农田、加工场地均阻挡新建，不能覆盖、替换材质、自动跳过或免费复用旧路。重铺同格需要先拆除。占用或越界格标红；资金不足标红总费用并显示可用金额。第二次点击仍尝试提交并明确报告失败；失败整段不建、不扣费、不清除环境装饰，保留起点、顺序与预览，不留下部分道路。

## 直线拆除

建造目录提供“拆除道路”工具。同样短按起点、移动预览、短按终点提交。按真实鼠标移动相对起点的主要网格轴选择直线，终点投影到该轴，不要求鼠标精确共线，也不生成 L 形；相等位移保留已有选择。只有实际待拆道路显示红色半透明标记，提示待拆道路格数。

范围可跨空格、农田和加工场地，也可包含不连续、不同材质道路；只移除范围内实际道路，不修改其他设施，不退款。范围没有道路时提示“没有可拆除的道路”并保留当前段；越界整段拒绝。退出工具后点击道路仍可打开独立详情，读取实际材质并拆除这一格。生产设施拆除继续一次释放整座九格，不能通过拆路工具移除。

## 连接与预览

正式道路按四邻格道路存在性自动选择孤立、端点、两种斜向直路、转角、丁字和十字外观；不同材质相邻也连接，没有手动旋转。每格纹理变体稳定选择，预览与建成后保持一致。

新建预览用“正式道路 + 当前空间有效候选道路”计算连接，候选内部连接，受影响旧路临时显示建成后的形状并保留材质；实际冲突格不能当作新路覆盖。拆除预览用“正式道路 − 当前待拆道路”计算保留道路的断开形状。预览使用真实半透明道路纹理和空间标记，不修改正式占用、材质、金币、设施或装饰；移动、隐藏和取消解除旧范围临时外观，跨缓存块的相邻道路同样刷新。材质边界、门前入口、中心磨损和散石仍待确认，不默认启用。

## 镜头与取消

左键或中键拖动仍平移镜头；拖动时隐藏预览，保留本段，松开不提交。镜头拖动位移不纳入轨迹，也不改已锁定 L 形顺序；松开后按当前鼠标格更新终点，下一次真实未按住鼠标的地图移动才可确定轴。缩放、窗口变化和键盘平移只更新终点，不代替鼠标轨迹。界面遮挡、离开窗口及跨界面按下／松开继续防穿透，回到地图恢复预览。

有未提交段时右键或 Esc 先取消当前段、回到选起点状态；没有当前段时退出工具。取消按钮直接退出工具。成功提交或仅取消当前段都清空本段起终点、轨迹及顺序，保留工具与材质；新建工具恢复鼠标单格起点预览，下一段重新短按选起点，不自动沿用上一终点。鼠标处若刚建成道路，按真实占用显示冲突，移到空格恢复有效预览。界面遮挡、拖镜头和离窗也隐藏未点击的起点预览，回到地图恢复；拆路工具未选择起点时仍不生成待拆段。正式道路仍是单格实例，不保存段归属或铺设历史。暂停时仍可预览、新建和拆路，工具不改变暂停状态。农田与加工场地沿用原建造、R 旋转和拆除操作，见[开局与建造](opening-and-building.md)。

## 与经营的关系

道路不创建农田、加工批次、水分或作物状态，不参与生产推进，也不触发空闲加工场地领取原料。工人按格距离与经营秒直线移动，可穿越占用；无路、有路、断路均可正常播种和浇水。道路不提供速度加成，连接仅是表现规则，不成为寻路规则。工人规则见[移动与多人调度](../../architecture/workers/worker-scheduler/implementation-movement-proposal.md)。

土地信息由 `LandOccupancy` 唯一维护，其他模块通过只读查询获取占用；移动耗时封装在 `WorkerScheduler` 内部。
