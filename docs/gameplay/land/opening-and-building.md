# 开局与建筑建造

地图为 384×384 基础格，每格 64×32 世界像素。农田和加工场地各占 3×3（192×96），九个子格组成一座设施、一份生产状态；道路占一个基础格。开局三座农田的锚点为 (189,189)、(192,189)、(195,189)，两座加工场地的锚点为 (189,192)、(192,192)。这些建筑免费直接建好；三人分别出生在各田中间格 (190,190)、(193,190)、(196,190)。农田尚未播种，由工人按经营节奏照料。

开局从七种作物中随机选主作物，以 50% 概率形成三块同种农田和两处同种加工场地；另有 50% 概率形成两块主作物农田、一块另一种作物农田，两处场地分别匹配这两种作物。同一市场种子生成同一开局配置，新游戏随机取种子。具体生成流程见[实现说明](../../architecture/game-state/farm-game/implementation-opening-layout.md)。

初始金币为 50.00。空地可建农田、对应加工场地或道路，无土地解锁步骤；农田与加工场地每座 10.00 金币，道路每小格 1.00 金币。任意空小格可作为建造锚点，不要求对齐三格跨度。生产设施从锚点沿两格轴各延伸三格，全部九格都须在地图内且空闲；任一子格冲突、部分越界或余额不足都会拒绝整次建造，不扣费、不留下部分设施。执行时重验当前占用和余额，成功只扣一座费用。

农田建成时默认种小麦，可在详情改种；加工场地在目录中选择品种。点击九个子格中的任意一个，均选择同一座设施、显示同一详情；改种只作用于一份作物状态，拆除一次释放全部九格，不退款。在释放的土地重建仍支付一座费用。移除时作物与加工中物品的处理分别见[作物](../production/crop-growth.md)和[加工](../production/processing.md)。地图外的拆除与改种失败，不影响其他设施。

道路在目录选择后逐小格连续铺设，显示灰色路面；成功后保持模式，取消或 Esc 退出。道路与生产设施的任一占用子格互斥，重复铺路也拒绝且不扣费。选中道路可在详情拆除一个基础格，不退款。道路不产生原料、加工批次或水分，不改变工人速度、碰撞或可达性；详见[道路布局](roads.md)。

建造和移除命令见[FarmGame 接口](../../architecture/game-state/farm-game/interface-farm-game.md)，玩家操作见[主界面接口](../../architecture/ui/main/interface-main.md)。`tests/unit/TestFarmGame.cs` 验证开局、按类型收费、道路互斥与执行时重验、无路/有路/断路三轮生产和余额限制；`tests/e2e/TestCoreLoop.cs` 验证目录和摆放流程。
