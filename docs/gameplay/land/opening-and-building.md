# 开局与建筑建造

地图为 384×384 基础格，每格 64×32 世界像素。农田和加工场地各占 3×3（192×96），九个子格组成一座设施、一份生产状态；道路占一个基础格。开局三座农田的锚点为 (189,189)、(192,189)、(195,189)，两座加工场地的锚点为 (189,192)、(192,192)。这些建筑免费直接建好；三人分别出生在各田中间格 (190,190)、(193,190)、(196,190)。农田尚未播种，由工人按经营节奏照料。

开局只从当时季节适宜的作物中随机选主作物，以 50% 概率形成三块同种农田和两处同种加工场地；另有 50% 概率形成两块主作物农田、一块另一种适季作物农田，两处场地分别匹配这两种作物。当前新游戏始于春季，因此初始田不会选到甘蔗；三块田都可由工人立即开始照料。同一市场种子生成同一开局配置，新游戏随机取种子。具体生成流程见[实现说明](../../architecture/game-state/farm-game/implementation-opening-layout.md)。

初始金币为 50.00。空地可建农田、对应加工场地或道路，无土地解锁步骤；农田与加工场地每座 10.00 金币，道路每小格 1.00 金币。任意空小格可作为建造锚点，不要求对齐三格跨度。生产设施从锚点沿两格轴各延伸三格，全部九格都须在地图内且空闲；任一子格冲突、部分越界或余额不足都会拒绝整次建造，不扣费、不留下部分设施。执行时重验当前占用和余额，成功只扣一座费用。

农田建成时默认种小麦，可在详情改种；加工场地在目录中选择品种。点击九个子格中的任意一个，均选择同一座设施、显示同一详情；改种只作用于一份作物状态，拆除一次释放全部九格，不退款。在释放的土地重建仍支付一座费用。移除时作物与加工中物品的处理分别见[作物](../production/crop-growth.md)和[加工](../production/processing.md)。地图外的拆除与改种失败，不影响其他设施。

在目录选择任意建筑后，鼠标指向的基础格是候选锚点；预览按建筑占地属性展开完整占地，正常格淡绿、实际占用或越界格标红，并显示半透明建筑外观。任一格冲突仍拒绝整座建造。金币不足时保持空间配色，底部标准费用标红并显示可用金币；委托冻结金额不能用于建造。预览不扣费、不登记土地、不创建生产状态。

左键短按在松开时建造一座，成功和失败都保留所选类型，成功后不弹出详情；道路同样每次点击只铺设一份占地，不提供成段铺路。右键、Esc 和取消按钮对所有类型统一退出摆放并清除预览。进入摆放保留当前暂停状态，暂停时仍可预览和建造。左键或中键拖动平移镜头时隐藏预览，松开不建造；缩放、键盘平移和窗口变化后预览跟随鼠标下的新格。鼠标在界面上或离开窗口时隐藏预览，移回地图恢复；界面点击与跨界面的按下、松开不穿透建造。

农田与加工设施只在摆放前可按 R 或点击“旋转 R”按钮，依次切换 q0→q1→q2→q3→q0；按钮显示当前候选朝向。每一座新候选从 q0 开始，成功建造后下一座重置 q0，失败保留本候选方向；取消摆放丢弃方向，重新选类型也从 q0 开始。旋转免费，暂停时可操作，输入框内输入 R 不触发旋转。当前设施均为3×3，四向占地和工作中心相同，不影响生产进度、工人任务、库存或金币；建成后不提供旋转操作，开局设施均为 q0，道路不提供旋转入口。未来实际引入非方形设施时，方向须同时改变正式占地，本次不增加新尺寸或形状框架。

道路显示灰色路面，与生产设施的任一占用子格互斥，重复铺路也拒绝且不扣费。退出摆放后选中道路可在详情拆除一个基础格，不退款。道路不产生原料、加工批次或水分，不改变工人速度、碰撞或可达性；详见[道路布局](roads.md)。

建造和移除命令见[FarmGame 接口](../../architecture/game-state/farm-game/interface-farm-game.md)，玩家操作见[主界面接口](../../architecture/ui/main/interface-main.md)。`tests/unit/TestFarmGame.cs` 验证开局、按类型收费、道路互斥与执行时重验、无路/有路/断路三轮生产和余额限制；`tests/e2e/TestCoreLoop.cs` 验证目录和详情流程，`tests/e2e/TestBuildPlacement.cs` 验证全部建筑连续摆放、四向候选与实际朝向、成功重置与失败保留、R输入焦点、三种取消、冻结资金提示以及真实输入下的界面遮挡、镜头和暂停。
