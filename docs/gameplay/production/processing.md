# 原料加工

每种原料只能由[作物表](crop-growth.md)中对应的场地加工；加工操作免费，建造费用按[建造规则](../land/opening-and-building.md)。收获的原料先进入该作物的公共库存，空闲的匹配场地取走一份后开始加工，到期产出一份对应加工品。

库存窗口可分别设置七种原料的保留底线，默认 0，只接受非负整数，允许底线高于现存库存。空闲场地只能领取超过底线的部分，每次一份；库存等于或低于底线时等待。底线修改本身不触发领取，下一次经营步进的领取阶段按新值检查。提高底线不退回已投入的原料、不重置加工进度；反复设置也不重复启动批次。

多座空闲场地按稳定格序领取：先较小的 Y，再较小的 X，与建造先后无关。新建加工场地仍立即让全部空闲场地按这一顺序尝试领取，检查当前底线，不仅检查新场地。公共库存积压不阻止农田收获。

不同作物的加工时间见[作物表](crop-growth.md)。移除正在加工的场地时，已投入原料消失，不返还库存。公共库存中的原料可按品种直接出售；已投入加工的原料不再属于可售库存。两类出售规则见[出售与价格](../trading/sales.md)。

场地分配与完成时机由[FarmGame 的经营步进](../../architecture/game-state/farm-game/implementation-tick-order.md)协调；tests/unit/TestFarmGame.cs 检查匹配、移除和切换后的结果。

选中加工场地时，详情区分缺少对应原料、原料受保留底线限制、待领取原料和加工中，并显示从投入原料到完成的加工周期（以“天”显示）、对应加工品的当日售价和公共加工品库存。降低底线后到下次领取前可显示待领取原料。半天的精确目标若落在整秒之间，在首个达到目标的经营步进完成。库存按品种共享，并非每座场地各自持有；农田详情只显示原料信息。
