# 作物生长与选种

七种作物均由农田生产。新建农田默认种小麦；每块农田独立选择作物。改种或移除农田会丢弃尚未收获的作物；改种保留田块水分，移除清除水分。种子免费。完整供水规则见[农田供水与降雨](water-and-rain.md)。

一名工人每秒至多完成一次播种或浇水。作物获得水后按下表的精确天数生长，达到目标的首个整秒自动收获指定数量的原料并进入公共库存。播种和等待供水的时间不计入生长周期。当前没有“成熟但未采集”状态；未来若加入采集，该状态的跨季保护规则记录在 [issue #38](https://github.com/Fotally/Farm-Exchange/issues/38)。
