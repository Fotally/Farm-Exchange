# 年度耕作表操作

开局即可从底部“年度耕作表”打开编辑窗口，农田详情也有入口。表按年度循环安排日期，多块田可以引用同一份具名表，实际播种和生长分别推进。

首次打开时可以直接拖入作物，名称尚未填写也能新增、移动和移除条。名称只影响保存：保存前必须填写名称，空名会明确拒绝且不修改已保存表。清空正在编辑的表名也保留草稿编辑和真实排程校验，不会替玩家补默认名称。

## 编辑与共享

1. 点击“新建年度表”，输入名称，并为整张表选择“立即改种”或“预备下一轮”。
2. 从作物区拖入春、夏、秋、冬时间图；每条长度是获水后的完整生长周期，空白为休耕。图中金线表示今天，图上位置是安排日期，不保证工人届时已完成播种浇水。
3. 拖动时抓取完整条的中心，预览左边对应落位的开始日期；放下后跨季条分为同一轮的多个片段，冬末到春初连续处理。拖动任意片段会移动整条。时间带、作物条及选中/风险轮廓采用像素木作主题的方形样式；保留月份，并在每7个游戏日绘制一周刻度。
4. 条内空间充足时，居中显示作物名、完整周期及“月/日→月/日”的起止日期；结束在下一年时注明“次年”。短萝卜条或较窄跨季片段放不下完整文字时，鼠标悬停显示整轮作物、周期、完整起止日期和跨季关系，移开即消失；不裁掉日期或缩小字号。点击条还可查看下方完整说明，点击“移除选中整条”从草稿移除。
5. 悬停落点时先检查新增或替换后的完整排程，并说明拒绝原因。重叠、不同作物不足一天间隔以及不适季起点均不能落位；拒绝后原条、草稿和已保存表保持原值。同种可相邻，不同作物至少留一天，冬春首尾同样检查。适季开始但跨入禁生季仍可安排，红色轮廓提示枯萎清除风险；不自动换作物或改日期。
6. 点击“保存共享表”，再从左侧农田列表勾选多块田，点击“应用已保存表到勾选田”。应用和编辑保留当前轮；后续按表的执行方式推进。

共享表列表显示真实引用数量，农田勾选行显示引用名称；保存旁提示修改会影响几块引用田。编辑草稿在保存前不改变共享表。窗口每秒刷新、关闭重开和暂停不会推进经营或覆盖草稿；输入焦点和勾选保留。农田很多时列表可以滚动。

共享表列表的普通、悬停、选中、选中悬停及焦点状态均使用深色文字；选中行保持浅绿高亮，键盘焦点使用透明描框，名称不会在浅底上切换为白字。

选择已保存共享表后，点击左侧“共享年度表”标题旁的“删除表”删除整张表；未保存的新表草稿不能删除。“移除选中整条”仍只删除草稿中的一条作物安排，保存后才生效。整表删除会立即解除全部农田引用和该表后续安排，保留各田当前作物、待水或生长阶段、剩余时间与水分；之后各田按当前作物自动复种，仍遵守原有季节限制并等待工人实际播种、浇水。其它共享表和独立手动预备保持，金币、库存和经营日期不变。删除成功切换到新表草稿，表编号不会复用；失败保留当前编辑。

农田列表的普通、悬停、勾选、勾选悬停及焦点状态均使用深色文字，保持浅色窗口底上的可读对比。删除条不会复用旧编号；即使保存空表后重新选择，新条仍作为新的独立轮次安排，已经执行的旧条保持原年度凭据。

暂停时保存修改也会即时更新地图上的当期作物外观，无需继续经营才显示。选作物期间仍可从详情移除本田；移除成功后该田的选种窗口随之关闭。

## 看实际状态与手动接管

农田详情分别展示共享表、实际剩余游戏天数、待水状态及预备作物或休耕；待水时不显示虚构的完成日期。年度图的起止日期是排程，详情的剩余时间是实际生产。

初年春初衔接冬春连续条时，条的开始日期显示“上一年度 X月X日”，保持同一轮跨年的关系；其他计划起点显示实际游戏年份与月日。

- “立即改种”打开作物窗口，操作说明明确会解除本田共享表引用、清空耕作安排并丢弃当前未收获作物，田块水分保留。选作物后立即处理指令，工人仍需实际播种浇水。
- “预备下一轮”单独打开作物窗口，说明解除本田引用并清空耕作安排，保留当前作物；下一轮接续手动指定的目标，不额外等一天。

手动接管只影响本田，其他引用田仍使用共享表。作物卡展示当前季节播种提示；预计越过禁生边界属于风险，当前适季仍可播种，禁生季节等待适季。手动接续开始后沿用手动选种自动复种。

按 Esc 关闭年度表。具体年度执行与播种规则见[季节耕作表](seasonal-cultivation.md)，作物周期见[作物与选种](crop-growth.md)。
