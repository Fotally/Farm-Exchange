# 农田供水与降雨

每块农田独立留存是否有水。工人浇水和降雨都能供水；已播种的作物获得水后开始生长，尚未播种的农田可把雨水留到雨停后播种使用。已有水分的农田播种时直接开始生长，不再安排一次浇水动作。干田播种者留在同田，下一完整模拟秒完成浇水；播种与供水不在同一秒完成。生长中再次遇雨不会重置进度。

降雨在该秒经营步进的开始生效，随后推进已有作物生长、加工、工人移动或动作，最后换日。雨水使已播种作物在本秒开始生长；工人在同秒雨后完成播种时可使用留水。人工浇水任务在移动或工作中已被雨水满足时取消，释放认领并继续轮转，不重复供水；播种任务遇雨可继续，完成后省去浇水。作物成熟时清除本轮水分，即使本秒仍在下雨也不立即重新润湿；下一秒仍下雨时才再次供水。人工浇水满足同一轮需水条件。

立即改种会丢弃当前未收获作物并保留田块水分，同品种也适用；预备下一轮保留本轮，正常收获仍清除水分。耕作表休耕只停止空田播种，保留空田留水，已经播种的本轮仍可正常浇水。移除农田连同水分清除。换季成熟结算后，待水或仍未成熟的生长中作物进入禁生季节时，自动清除本轮作物、进度和水分；空田原有留水不受换季影响。若失败后的下一秒仍下雨，空田可再次留水，但不适季作物仍不能播种。当前主场景尚无天气生成或降雨显示，正常游玩仍由工人浇水；供水规则可通过显式逐秒降雨输入验证。
