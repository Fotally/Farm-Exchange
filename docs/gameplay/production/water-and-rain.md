# 农田供水与降雨

每块农田独立留存是否有水。工人浇水和降雨都能供水；已播种的作物获得水后开始生长，尚未播种的农田可把雨水留到雨停后播种使用。已有水分的农田播种时直接开始生长，不再安排一次浇水动作。生长中再次遇雨不会重置进度。

降雨在该秒经营步进的开始生效，随后推进已有作物生长、加工、工人动作，最后换日。雨水使已播种作物在本秒开始生长；工人在同秒雨后播种时可使用留水。作物成熟时清除本轮水分，即使本秒仍在下雨也不立即重新润湿；下一秒仍下雨时才再次供水。人工浇水满足同一轮需水条件。

改种会丢弃当前未收获作物并保留田块水分；移除农田连同水分清除。当前主场景尚无天气生成或降雨显示，正常游玩仍由工人浇水；供水规则可通过显式逐秒降雨输入验证。季节失败时的清理属于后续越季任务。

作物时长与收获数量见[作物生长与选种](crop-growth.md)；业务相位和公开输入见 [FarmGame 推进顺序](../../architecture/game-state/farm-game/implementation-tick-order.md)。
