# 农田供水与降雨

每块农田独立留存是否有水。工人浇水和降雨都能供水；已播种的作物获得水后开始生长，尚未播种的农田可把雨水留到雨停后播种使用。已有水分的农田播种时直接开始生长，不再安排一次浇水动作。干田播种者留在同田，下一完整模拟秒完成浇水；播种与供水不在同一秒完成。生长中再次遇雨不会重置进度。

降雨在该秒经营步进的开始生效，随后推进已有作物生长、加工、工人移动或动作，最后换日。雨水使已播种作物在本秒开始生长；工人在同秒雨后完成播种时可使用留水。人工浇水任务在移动或工作中已被雨水满足时取消，释放认领并继续轮转，不重复供水；播种任务遇雨可继续，完成后省去浇水。作物成熟时清除本轮水分，即使本秒仍在下雨也不立即重新润湿；下一秒仍下雨时才再次供水。人工浇水满足同一轮需水条件。

立即改种会丢弃当前未收获作物并保留田块水分，同品种也适用；预备下一轮保留本轮，正常收获仍清除水分。耕作表休耕只停止空田播种，保留空田留水，已经播种的本轮仍可正常浇水。移除农田连同水分清除。换季成熟结算后，待水或仍未成熟的生长中作物进入禁生季节时，自动清除本轮作物、进度和水分；空田原有留水不受换季影响。若失败后的下一秒仍下雨，空田可再次留水，但不适季作物仍不能播种。主场景使用自然预排天气，开发／测试局可在创建时选择显式矩形设置模式；两种模式互斥，单秒与批量推进读取同一天气状态，不再接受逐秒全局降雨布尔输入。显式设置本身不立即供水，下一经营秒开始才应用。

作物时长与收获数量见[作物生长与选种](crop-growth.md)；业务相位和公开输入见 [FarmGame 推进顺序](../../architecture/game-state/farm-game/implementation-tick-order.md)。


每座3×3农田的九个占地基础格只作一次整田判断：存在降雨即整田降雨；无雨但存在多云即整田多云；九格全晴才为晴天。角落一格也可决定整田天气。供水、产量和详情共用这一结果，不按中心点或覆盖面积混合，不增加九份水分。多格同时降雨仍只供一次水。

天气状态在完整经营秒结束后同步到当前日历，供画面和查询读取；新生效或刚结束的天气从下一经营秒开始作用于农田，不回溯改变刚结束一秒的生长与产量。天气边界与换季同时到达时，同样先完成原天气下的生长及促熟，再同步新日期和当前天气。自然预排及显式开发输入规则见[天气](../world/weather.md)。
