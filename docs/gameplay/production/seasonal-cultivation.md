# 季节耕作表

关联 [#42](https://github.com/Fotally/Farm-Exchange/issues/42)。耕作表开局即可使用，多块农田可以引用同一份具名年度安排，各田仍独立播种、供水和收获。年度共 336 天，春夏秋冬每季 84 天；表每年重复，冬春跨年连续处理。

每个条表示一次种植，长度为[作物表](crop-growth.md)的完整获水生长周期。条的位置是计划日期，工人仍需实际到田播种、浇水；不会按条的位置直接发放收成。空白为休耕，不同作物之间至少留一天空白，用于吸收工人播种、浇水产生的时间差。同种相邻条可以连续，n 轮就是 n 个完整周期、n 个独立条，不合并成一条。跨季片段仍属于同一个条、同一轮。

| 表级执行方式 | 行为 |
| --- | --- |
| 立即改种 | 下一不同作物条起点到达时切换，可丢弃当前未收获的一轮；空白及同种相邻起点保留当前轮，停止新播种。 |
| 预备下一轮 | 保留当前轮，按其预计结束日期对应的表位置预备目标；实际结束后接续有效条或按表休耕。 |

初次应用和修改共享表的操作本身保留农田当前轮；随后由表的执行方式处理日期事件。改表影响全部引用田，批量应用不会要求各田同时完成工作。当前轮待水时尚不能确定完成日期，必须等待实际供水，不猜测工人或未来降雨。

每条每年只执行一轮，不在条内自动复种；已经完全过去的条跳过，不补种旧条。条尾进入空白时不会清除已播种或生长中的一轮，仍允许供水、成熟；空白不启动新一轮。同种连续条也要等旧轮实际结束后才独立启用下一条，不能在同种起点重置未完成进度。一天空白是排程间隔，实际收获后不额外等待一天。预计结束落在空白时按表等待后续条起点；实际结束时重新核对表位置，旧缓存仍有效也不能遗漏更早的有效条。打开窗口、查询和编辑草稿不推进经营；暂停保持实际生产和计划执行。

手动指令优先，并只接管本田：

- **立即改种**：解除共享表关联并清空其预备目标，立即丢弃当前未收获一轮、保留水分、设置手动作物；同种立即改种也执行丢弃。
- **预备下一轮**：解除共享表关联，保留当前轮并设置手动下一轮作物。当前轮结束后接续目标，没有额外一天等待；目标执行后沿用手动自动复种。

两种手动指令仍需工人实际播种和供水，不删除共享表、不改变其他田。操作前由界面说明解除安排及可能的当前轮损失。

手动和计划均按当前季节适宜性决定能否播种。预计来不及成熟仅提示风险，不阻止适季播种；禁生季节仍禁止播种。相邻适季跨季保留生长，例如甘蔗夏秋继续本轮；进入禁生季节时按[作物与选种](crop-growth.md)处理本轮结局。当前轮的预计结束日期纳入具体边界是否进入禁生季，空白缓冲仍遵守该规则；失败清理不会发放收成。编辑器风险允许保留，不自动换作物或重排。拖动编辑与批量控件说明见[操作说明](seasonal-cultivation-ui.md)。
