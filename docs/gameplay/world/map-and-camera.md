# 地图、选择与镜头操作

地图为 384×384 格等距菱形，格坐标为 (列, 行)，两者均在 0..383。地块宽 64 像素、高 32 像素；格中心在地图本地坐标中为 x = (列 − 行) × 32、y = (列 + 行) × 16，地图节点移动时其全局位置随之变化。屏幕选格先转换到地图本地坐标，再逆算并取最近格中心，地图外不选择。

左键短按选择格，右侧显示土地状态；左键移动达到 8 个逻辑视口像素转为拖动镜头，松开立即停止，下一次短按仍能选格。中键拖动也可平移。鼠标滚轮以镜头中心缩放，范围为 1.25～2 倍；WASD 或方向键平移。镜头中心限制在地图菱形内，默认设计与主要验收基准为 1920×1080。可见基础格数不等于生产设施数，一座生产设施占九格。

同一显示器、同一系统 DPI 下，扩大窗口或进入全屏会显示更多地图；同一玩家倍率下农田、格子和人物保持原来的屏幕像素大小，镜头中心和滚轮选择不变。UI采用独立像素尺寸：窗口扩大只改变定位与可用空间，不改变设定倍率。统一接口分别设置整体UI倍率与字体倍率，前者同步面板、布局、图标和文字，后者在此基础上单独调整字体。默认 1.25 倍时，一个基础格为 80×40 屏幕像素，一座农田或加工场地为 240×120；1280×720、1920×1080、2560×1440 下均保持这一尺寸。

倍率越小，地图上的对象越小、可见范围越大。现有下限仍为 1.25，用户询问的 1 倍尚未启用：若以后允许缩到 1 倍，一座农田会变为 192×96，宽高各比 1.25 倍小 20%；只改下限不会自动改变开局或玩家当前倍率。

绿色为空地，棕色为农田，蓝灰色与白色方块为加工场地。空闲农田中央彩色点表示所选作物，黄色小点表示已播种，较大彩色点表示生长中；农田与加工场地各完整占据3×3小格（192×96），每座只在中央小格显示一个标记；道路占1×1小格并显示灰色路面。黄色边框表示当前选中整座设施；空地和道路显示单格选框。地图边缘与选中框独立绘制。

顶部中央显示日期与暂停，右上显示金币与工人，左侧经营近况展示真实设施数量及操作反馈。底部中央提供建造、库存、市场和年度耕作表入口。建造按钮进入目录，选建筑后点击任意空小格作为锚点摆放；完整3×3占地必须在地图内且没有冲突，每座生产设施仍收10.00金币，道路每格1.00金币。点击设施任一占用小格时，右侧可拖动详情窗口显示同一建筑锚点并提供改种或整体移除；拆除释放整座占地且不退款；详情位置在本次运行内保留。市场窗口显示十四商品独立的当前报价、上次报价、实际涨跌与公共库存；选中商品后可按数量买入、卖出或出售该商品全部库存，保留按品种出售全部原料与出售全部加工品快捷。完整层级见[主界面接口](../../architecture/ui/main/interface-main.md)。地图绘制接口见[WorldMap](../../architecture/world/world-map/interface-world-map.md)，镜头输入接口见[CameraController](../../architecture/world/camera-controller/interface-camera-controller.md)。tests/unit/TestWorldMap.cs 与 tests/integration/TestCameraInteraction.cs 检查坐标和输入行为。

初始镜头位于新地图中心，中心本地坐标为 `(0, 6128)`。开局三块农田锚点为 `(189,189)`、`(192,189)`、`(195,189)`，加工场地为 `(189,192)`、`(192,192)`；三名工人出生于各农田中央小格，人物保持既有64×64帧与上移20像素的表现。工人每经营秒移动3小格，仍为一座标准田跨度；显示插值和动画不推进经营。

选择建造类型后，鼠标指向的基础格就是候选锚点，占地按建筑属性展开；地图显示完整淡绿半透明覆盖、细格线、半透明类型标记与锚点小环。仅实际占用或越界格标红，其余保持绿色；越界不自动移位，任一冲突仍拒绝整座建造。金币不足只通过费用文字反馈，不将空闲格标成冲突。预览几何与当前设施尺寸分离，外围从实际占地格的外边生成。

摆放时左键短按在松开时建造一座，成功和失败都保持当前类型；成功后不弹详情。右键、Esc、取消按钮退出同一个摆放流程。左键或中键拖动时隐藏预览，松开只结束拖动；滚轮、键盘和窗口尺寸改变后，预览重新跟随鼠标下的世界格。鼠标移入界面或离窗隐藏预览，移回地图恢复；界面点击及跨界面的按下/松开都不建造。预览和取消不改变资源或生产状态，进入摆放保持当前暂停状态，暂停时仍可主动预览与建造。
