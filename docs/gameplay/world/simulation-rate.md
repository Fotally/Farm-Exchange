# 经营速率与暂停

顶部日期右侧的倍率选择提供 **0.5×、1×、2×**。倍率只改变现实等待时间，经营中的作物、加工、工人、日历、报价和委托仍按相同完整经营秒结算。游戏日期与生产周期不因选择倍率改变。

暂停和切换倍率保留已经等待的半秒等未完成经营秒。暂停期间不继续累计现实时间，恢复后从原进度继续，不补算暂停时长。暂停仍可进行既有主动交易。

工人暂停立即对齐真实经营位置，动画保留当前帧并暂停。0.5×、1×、2×时行走表现和动画按相同倍率播放。扩大窗口继续保持人物像素尺寸和玩家地图缩放，倍率不会放大地图或界面。

开发构建额外提供有限正整数倍率及 5×、10×、20×快捷项；高倍率人物直接显示最新真实位置，动画保持正常播放速度。发布版本只保留公共三个倍率。开发流程在现场运行时，玩家主动选择倍率会中断整个自动流程；已经发生的交易、生产和订单保留，当前局按玩家选择继续正常经营。
