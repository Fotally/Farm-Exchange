# 经营速率与暂停

顶部日期卡的竖线右侧、暂停按钮左侧显示当前倍率。点击倍率按钮按 **1× → 2× → 0.5× → 1×** 循环，悬停可查看下一次点击的倍率。倍率只改变现实等待时间，经营中的作物、加工、工人、日历、报价和委托仍按相同完整经营秒结算。游戏日期与生产周期不因选择倍率改变。

暂停和切换倍率保留已经等待的半秒等未完成经营秒。暂停期间可以点击倍率按钮，但不会恢复经营或推进经营秒；恢复后从原进度继续，不补算暂停时长。暂停仍可进行既有主动交易。

工人暂停立即对齐真实经营位置，动画保留当前帧并暂停。0.5×、1×、2×时行走表现和动画按相同倍率播放。扩大窗口继续保持人物像素尺寸和玩家地图缩放，倍率不会放大地图或界面。

开发构建额外提供1～16 的整数倍率及 5×、10×、16×快捷项；主倍率按钮显示实际开发倍率，点击一次回到1×，随后继续公共循环。高倍率人物直接显示最新真实位置，动画保持正常播放速度。发布版本只保留公共三个倍率。开发流程在现场运行时，玩家主动点击倍率会中断整个自动流程；已经发生的交易、生产和订单保留，当前局保留玩家倍率与原暂停状态。
