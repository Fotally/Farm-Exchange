# 地区天气

关联 issue：[#34](https://github.com/Fotally/Farm-Exchange/issues/34)。天气以经营时间推进，暂停停止；默认晴天。首版只有互斥的晴天、多云和降雨，不提供天气预报或玩家天气控制。

## 自然天气数据

正式数据唯一入口为 `assets/gameplay/weather/weather_rules.json`。多云／降雨权重是暂定设计数据，算法读取具名配置，不在生成算法中写死。

| 配置 | 生效值 | 含义 |
| --- | ---: | --- |
| `CycleYears` | 10 | 新局加载时一次生成的循环年数 |
| `DaysPerYear` | 336 | 与正式日历一致的每年日数 |
| `MinimumIntervalDays`／`MaximumIntervalDays` | 1／3 | 相邻候选开始日期间隔 |
| `MinimumDurationDays`／`MaximumDurationDays` | 2／4 | 每片候选天气持续日数 |
| `MinimumRegionSizeCells`／`MaximumRegionSizeCells` | 96／192 | 每片矩形宽、高各自的基础格范围 |
| `MaximumActiveRegions` | 3 | 同一时刻活动片数上限 |
| `CloudyWeight`／`RainWeight` | 4／3 | 多云／降雨候选类型相对权重 |

10 年为 3360 游戏日、172800 经营秒，即 1× 不暂停时的 48 小时。第一个候选在开局之后，零秒全图晴天。候选空间位置固定，宽高独立取整，完整位于地图范围内。发生空间冲突或数量超限时直接拒绝该候选，不覆盖、不重抽；因此实际天气间隔可能更长。

预排检查候选的整个生效区间与循环首尾接缝。到期位置恢复晴天；跨循环末尾的天气保留原持续时间，第二个及后续循环开头可继续上一周期尾部天气。运行中只按既有排程生效、结束和循环，不每日随机、不临时补排。

## 整田天气与供水

3×3 农田的九格只要有一格降雨，整田为降雨；没有雨但有一格多云，整田为多云；九格均晴才是晴天。角落一格也能决定整田天气。供水、产量及农田详情共用此判定，不采用中心点或面积比例。

经营秒开始时雨供水。整田只保留一份已有水分状态，重复雨格不额外累计、不重置生长；本秒收获清水后不再立即润湿，下一经营秒仍降雨才供水。生长与实际产量规则见[作物与选种](../production/crop-growth.md)和[供水与降雨](../production/water-and-rain.md)。

## 显式开发测试输入

创建局时固定选择自然预排或显式模式。正式主场景使用自然天气；显式模式只服务开发／测试，不生成自然排程，不在运行中切换模式或修改自然预排表。

显式设置支持任意合法地图内矩形，包含全图，不受自然区域 96～192 格尺寸限制；仍完整检查正宽高、越界、互斥及同时最多三片。显式区域保持到完整清除，清除恢复默认晴天。失败零修改，不裁剪、覆盖、恢复旧层或登记活动晴天区。旧逐秒雨布尔输入已迁移到这一天气权威状态。

## 表现与详情

地图只表现当前真实可见区域：晴天沿用原画面，多云为低透明度灰蓝云影，雨区增加稀疏斜雨和少量落地短效果；雨点落点不越出真实雨区，UI 不受染暗。视觉随机与经营随机独立，动画不执行供水或收获。暂停停止天气动画，高倍率控制密度，按至少 1920×1080 验收。

农田详情仅新增整田“当前天气”；现有产量改称“基准产量”，不显示未来随机收获量、倍率或天气计算过程。
