# 地图与交互

## 代码对应

- `project.godot`：Godot 项目入口、窗口大小、C# 程序集和渲染方式。
- `FarmExchange.csproj` 与 `NuGet.Config`：C# 项目及指定引擎自带的本地 NuGet 包源。
- `scenes/main.tscn`：地图、镜头、状态栏与经营按钮的场景结构。
- `scripts/WorldMap.cs`：128×128 等距网格的 8×8 分块绘制缓存、坐标换算、格子选择和菱形边缘；接口与同步规则见 `design/地图系统-分块绘制缓存接口.md`。
- `scripts/CameraController.cs`：区分左键点击与拖动，控制镜头平移、缩放和活动范围。
- `scripts/Main.cs`：连接格子选择、经营命令、计时器与界面。
- `tests/unit/TestWorldMap.cs` 与 `tests/unit/test_world_map.tscn`：独立检查角落、内部格子、格边界和地图外接矩形的坐标规则。
- `tests/integration/TestCameraInteraction.cs`：检查镜头缩放、选格、拖动和松开后的输入行为。

## 坐标约定

格坐标为 `(列, 行)`，均在 `0..127`。地块宽 64 像素、高 32 像素，格中心的世界坐标为：

```text
x = (列 - 行) × 32
y = (列 + 行) × 16
```

反向选择时先把屏幕位置变换到地图本地坐标，再逆算并取最近的格中心。地图数据和可选择格子都限定在列、行 `0..127`。地图按 8×8 格分为 256 块，只显示与视窗相交的块；镜头移动或缩放只更新块的可见性，已有绘制结果保持缓存。经营命令和 tick 完成后，地图扫描全世界快照，只有外观变化的块才重建带顶点颜色的网格；屏幕外块在进入视野时绘制。经营计算不受视野影响。菱形边缘与选中框独立绘制。相邻的同类地块使用统一颜色并略微重叠绘制，不显示逐格边线，避免缩放时出现明显接缝。灰色表示未解锁，绿色表示已解锁空地，棕色表示农田，蓝灰色和白色方块表示加工场地；空闲农田中央的小彩色点表示所选作物，黄色小点表示已播种，较大的彩色点表示生长中，颜色随作物变化。黄色边框仅表示当前选择。

## 操作

- 开局镜头朝向地图中心；中心 `(63,63)`、`(64,63)`、`(65,63)` 已是农田，`(63,64)`、`(64,64)` 已是对应加工场地。选择任一预置建筑可查看具体作物或场地。
- 左键短按：选择格子，在右侧查看土地状态并操作。
- 选中已建农田：在“农田作物”下拉框选种。切换时丢弃未收获作物。
- 选中已解锁空地：在加工场地下拉框选定类型，再点击建造；农田建成后默认种小麦。
- 右侧面板可滚动，显示六种作物的原料、加工品库存和当天售价；商店按钮出售全部加工品。
- 左键拖动：平移镜头；拖动距离达到 8 像素后不再触发选格。松开左键后立即结束拖动，继续移动鼠标不会平移镜头，下一次短按仍可选格。中键拖动也可平移镜头。
- 鼠标滚轮：以镜头中心缩放，范围为 1.25～2 倍；主场景默认使用 1.25 倍，也就是玩家可以看到的最远视野。
- WASD 或方向键：平移镜头。

镜头中心按格坐标限制在 128×128 地图菱形内。接近地图边缘时，画面仍可能包含空白区域，但镜头不能继续移入地图外的矩形角落。

项目基准视窗为 1280×720。在玩家确认的最远视野 1.25 倍下，按包含屏幕边缘部分可见地块的口径，单屏最多出现 682 格；相机不允许缩小到更低倍率。

满地图图形性能测试会读取 `WorldMap.LastVisiblePlotCount`。这个数是与视窗相交的地图块中包含的候选地块数，包含块内屏幕外的格子，不能当作实际屏幕可见格数。报告同时记录采样期间重建网格的块数；镜头移动不会逐帧重建这些块。

## 验证

使用项目指定引擎打开 `project.godot` 并运行主场景。在项目根目录执行以下命令编译 C#：

```text
dotnet build FarmExchange.csproj
E:\Godot\Godot_v4.7.2-stable_mono_win64\Godot_v4.7.2-stable_mono_win64_console.exe --headless --path . --scene res://tests/unit/test_world_map.tscn
```

镜头交互回归检查由 `tests/integration/TestCameraInteraction.cs` 执行：左键拖动后松开、继续移动鼠标，镜头应停留原位；即使释放事件被界面拦截，下一帧也应结束拖动；随后短按应能正常选格。完整场景测试命令见 `构建与验收.md`。
