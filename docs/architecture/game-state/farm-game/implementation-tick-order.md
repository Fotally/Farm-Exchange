# FarmGame 的经营步进顺序

对应[FarmGame 对外接口](interface-farm-game.md)的 AdvanceTick。`FarmGame` 只协调推进相位；农田及其目标有效性由 `FarmingSystem`、加工状态由 `ProcessingSystem`、三名工人的位置/任务/共享轮转与认领由 `WorkerScheduler`、分类库存由 `Inventory`、共享耕作表与本田安排由 `CultivationPlanBook` 唯一维护。调用方只获得聚合快照与结果。

每次步进代表一模拟秒，依次：

1. 若本秒输入降雨，按空间实例锚点索引顺序对全部现有农田各一次调用 `FarmingSystem.SupplyWater`；暂停时不应用降雨。
2. 按空间实例锚点索引顺序各一次推进 `FarmingSystem` 的生长和 `ProcessingSystem` 的在加工批次；到期结果由 `FarmGame` 交给 `Inventory` 入库。收获清除本轮水分，本秒降雨不立即补水。成熟田入库后先通知计划 Module 的 `Harvested`：计划田先关闭空田播种并保存目标，防止本条复种或下一条借旧日历提前播种；手动预备仍即时接续目标。若本步将跨季，对新季禁生的生长中作物按精确剩余单位执行内部促熟；成功仍走同一 `CollectHarvest` 入库和计划通知。
3. 按 `Y * 384 + X` 递增顺序让 `ProcessingSystem` 的空闲场地，通过 `Inventory.TryTakeRawForProcessing` 领取超过该种当前底线的一份原料；后一个场地读取前一个扣减后的数量。
4. 调用一次 `WorkerScheduler.AdvanceOneSecond`，按固定编号让三人各推进完整一秒；内部先统一释放失效认领，再选择有效且未认领的农田并推进移动或工作。实际工作经 `FarmingSystem.TryCompleteWork` 重验目标凭据、动作需求与播种条件；到田的移动秒不同时播种，干田播种与原地接续浇水分别占完整一秒。湿田播种后直接生长；`WorkerActed` 聚合本秒是否至少一人真正完成动作，移动不计入。工人完成后立即调用计划 Module 的 `RecordSownCrops`，仅登记实际播种凭据，在下一个日历/换季清理相位前保留本步发生的 Sow；不查询预备安排或执行日期事件。
5. `GameCalendar` 累计一秒；跨季时让 `FarmingSystem.ClearDisallowedCrops` 按新季节一次清理剩余禁生的待水或生长中作物及水分、进度，保留农田与选种；跨入新日时交 `MarketQuotes.Advance` 公布前日消息或执行本次正式报价，非报价日价格保持。随后按新累计精确单位调用 `CultivationPlanBook.Synchronize`，执行到期日期事件、发现供水确定的完成日期或换季中断并更新相关预备缓存，不按每日重新扫描表。日历进入新日与行情实际报价分别具有独立语义。
6. 交 `TradeOrderBook` 按原建单顺序各检查一次活动委托，使用刚更新的正式价格与日历；同单多个条件组成立不重复执行，后单读取前单成交后的资源。持续目标数量按当时总库存计算，一次目标用建单时锁定数量；资源不足或条件未满足保持等待，失败零修改。一次成交消费该单冻结资源并释放差额，持续策略不冻结。

生产时长统一用整数比例单位累计：一模拟秒推进 7 单位，一游戏日为 360 单位，半日为 180 单位。作物获得水或场地领取原料时设置目标；之后每秒扣除 7 单位，首次达到目标时收获或完工。步进开始的降雨让待水作物从本秒生长；工人在生长相位之后浇水或使用留水播种，则从下一步开始扣减。同一步到期与换日、跨季同时发生时，先结算成熟、加工、领取和工人动作，再换日更新行情，最后检查委托。暂停时全部经营相位不执行，恢复后不补现实时间；窗口失焦不会自动暂停。

内部补救仅对新季禁生的生长中作物生效：实际剩余单位乘 10 严格小于同作物完整周期单位；等于阈值、待水、适季跨季不触发，正常到期先结算。换季清理只处理未收获的本轮作物，不操作历史库存和金币，不产生额外工人工作。适季作物继续原进度，空田留水保持；同一步成熟已先收获入库，不会随后失败。清理使本轮目标凭据失效；下一工人相位释放旧任务和认领，旧动作不能操作新轮。空田的工作需求继续复用统一播种检查，禁生季节不再播种，改种或条件恢复后可继续。

降雨已在工人相位前满足供水时，调度取消过期浇水，既不重复供水也不重置生长；移动中的播种任务可以继续使用湿田。任务实际完成时使用本步开始的日历快照重验，不能因选取时允许播种就略过执行检查。暂停时工人位置和任务保持，恢复只推进下一模拟秒；界面插值不修改这些状态。

底线设置只修改 `Inventory` 中该品种的规则值，不调用领取阶段；下一经营步按新值检查。新建加工场地立即调用同一全场领取阶段，让全部空闲场地按稳定锚点序各一次检查当前底线；先前等待的场地同样参与，保持旧行为。提高底线不会退回批次投入物；暂停时仍可编辑底线，但不会因编辑推进经营。

主动交易也不调用领取阶段。买入原料进入同一公共库存，下一经营步领取时参与；若随后新建加工场地，则参与该命令已有的即时全场领取。交易在暂停时仍可执行，执行时使用已生效报价，不改日历或行情；原料底线只约束加工，手动出售可卖保留部分。

委托创建或编辑不执行成交；一次单冻结后，该部分现金不能用于建造或主动买入，冻结库存不能主动出售或加工。加工领取在委托检查前已完成，不回溯本秒领取：委托买入的原料从下一经营领取阶段参与。库存保留底线继续作用于可用原料，订单冻结不改变已启动批次。季节条件只读当前日历，不额外加价，正式价格仍由市场模块唯一维护。

道路只属于 `LandOccupancy`，不参加农田生长、雨水供给或加工遍历。铺路和拆路不主动执行空闲加工领取；道路连通与占用不改变工人移动或动作计时，经营快照与产出在相同任务布局下和无路时一致。

地图镜头、可见块和帧率不影响上述遍历；满地图 50 步检查覆盖角落实体。作物成熟与加工时长以[作物表](../../../gameplay/production/crop-growth.md)为准，出售结算以[交易规则](../../../gameplay/trading/sales.md)为准。

共享表的日期与缓存约定见[计划 Interface](../../cultivation/interface-cultivation-plan-book.md)。应用和编辑保留当前轮；立即表在下一日期事件可中断，预备表等待本轮结束。计划收获先关闭空田 Sow 并保留目标，原日历相位结束后 `Synchronize` 才按已生效日期重验启用；保持工人读取本步起始日历的原有约定。空白或本条已播种后用 `SetSowingEnabled` 阻止空田的 Sow，不阻止已有 Seeded 获水。手动下一轮在原收获相位接续，不追加一天等待；计划一天间隔只作用于排程验证。查询、草稿和动画不执行经营相位。
