# FarmGame 的开局布局实现

对应[FarmGame 对外接口](interface-farm-game.md)的构造与初始状态。构造时依据市场种子初始化市场曲线、中心土地、三块农田和两处匹配场地；没有指定种子时为新游戏随机生成。三名经营工人按固定编号分别从三座农田工作中心 `(190,190)`、`(193,190)`、`(196,190)` 开始，构造时空闲且没有目标；人数和位置不消耗随机数。

`FarmGame` 读取本局 `GameCalendar` 的开局季节，遍历 `CropCatalog.Crops`，按各作物的适宜季节筛出候选，并保存作物定义中的 `Kind`，不把作物枚举值当作候选下标。先从候选中均匀选主作物，再以等概率选择“三块同种”或“两块同种加一块另一种”。后一配置会从候选中排除主作物并选次作物，第三块农田用次作物，两处场地各匹配一种。随机调用仍依次为主作物、配置分支，以及仅在分支需要时抽次作物，同一种子可复现开局配置。五座预置建筑由构造过程同时写入 `LandOccupancy` 与对应的 `FarmingSystem` 或 `ProcessingSystem`，不扣开局金币。

中心坐标、金币和建造规则见[开局与建造](../../../gameplay/land/opening-and-building.md)。`tests/unit/gameplay/TestFarmGame.cs` 检查多个固定种子、旧抽样会选到春季甘蔗的种子、四季内部构造、两种配置、场地匹配、三名工人的固定编号与位置，以及三块赠送农田实际播种、浇水和开始生长。

三座农田锚点为 `(189,189)`、`(192,189)`、`(195,189)`；两处加工场地锚点为 `(189,192)`、`(192,192)`。设施各占固定 3×3，只有锚点登记生产状态。工人出生位置使用土地模块的 `BuildingFootprint.WorkCell`，与调度目标共用中心规则。
