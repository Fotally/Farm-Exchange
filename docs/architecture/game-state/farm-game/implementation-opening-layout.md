# FarmGame 的开局布局实现

对应[FarmGame 对外接口](interface-farm-game.md)的构造与初始状态。构造时依据市场种子初始化市场曲线、中心土地、三块农田和两处匹配场地；没有指定种子时为新游戏随机生成。

先从六种作物均匀选主作物，再以等概率选择“三块同种”或“两块同种加一块另一种”。后一配置会从剩余五种作物中选次作物，第三块农田用次作物，两处场地各匹配一种。五座预置建筑由构造过程直接放入地图，不扣开局金币。

中心坐标、金币和建造规则见[开局与建造](../../../gameplay/land/opening-and-building.md)。tests/unit/TestFarmGame.cs 检查相同种子的重复性、两种配置和场地匹配。
