# FarmGame 的开局布局实现

对应[FarmGame 对外接口](interface-farm-game.md)的构造与初始状态。构造时依据市场种子初始化市场曲线、中心土地、三块农田和两处匹配场地；没有指定种子时为新游戏随机生成。三名经营工人按固定编号分别从三座农田工作中心 `(190,190)`、`(193,190)`、`(196,190)` 开始，构造时空闲且没有目标；人数和位置不消耗随机数。

先从七种作物均匀选主作物，再以等概率选择“三块同种”或“两块同种加一块另一种”。后一配置会从剩余六种作物中选次作物，第三块农田用次作物，两处场地各匹配一种。五座预置建筑由构造过程同时写入 `LandOccupancy` 与对应的 `FarmingSystem` 或 `ProcessingSystem`，不扣开局金币；种子抽取的调用顺序不变。

中心坐标、金币和建造规则见[开局与建造](../../../gameplay/land/opening-and-building.md)。tests/unit/TestFarmGame.cs 检查相同种子的重复性、两种配置、场地匹配与三名工人的固定编号、位置和实际生产参与。

三座农田锚点为 `(189,189)`、`(192,189)`、`(195,189)`；两处加工场地锚点为 `(189,192)`、`(192,192)`。设施各占固定 3×3，只有锚点登记生产状态。工人出生位置使用土地模块的 `BuildingFootprint.WorkCell`，与调度目标共用中心规则。
