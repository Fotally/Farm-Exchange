# DraggableWindow 接口

对应 `scripts/ui/DraggableWindow.cs`。它是当前二级窗口共同的容器；构造时给出节点名、标题、初始位置与尺寸以及可选关闭动作。`Body` 接收窗口内容，`ShowRaised()` 显示、抬到同级最前并限制在视窗内。

标题栏负责开始拖动，窗口自身处理移动与释放；视窗尺寸变化时再次限制位置。窗口实例在本次运行中保留，关闭和重新打开沿用上次位置。全部经营窗口统一保留顶部 94 和底部 90 逻辑像素给常驻状态及操作栏。窗口尺寸取初始首选尺寸与当前可用范围的较小值，扩大视窗后恢复首选尺寸，位置仍保留并限制在可用范围。标题栏、关闭按钮和正文节点仍分别命名为 `Header`、`CloseButton`、`Body`。

#94 的纸面木框主题直接设置在每个窗口，独立场景测试同样取得主题。窗口将 `Body` 放入 `WindowScroll`，长正文可在较矮窗口整体滚动；窗口内已有的商品、目录、条件列表等局部滚动继续保留。调用方不能把正文最小尺寸强制设置为整个视窗高度。关闭后终止拖动，正文选择、滚动和按钮操作不会开始标题拖动。

标题采用明确单行，初始化时关闭自动换行。标题节点首次尚未取得排版宽度时，也不能按零宽将中文标题纵向分行、临时抬高窗口最小高度；正文的正常换行与滚动不受影响。`TestTradeOrdersWindow.RunLayoutChecks` 在真实主场景挂树后检查新委托窗口和原市场窗口标题均为完整单行，窗口仍位于 1280×720 的顶部、底部操作栏之间；不通过重新裁剪窗口尺寸掩盖子控件最小高度。

`Main` 不保存拖动中的窗口或复制边界计算；各具体窗口只维护自己的内容和操作意图。玩家操作见[主界面接口](../main/interface-main.md)。
