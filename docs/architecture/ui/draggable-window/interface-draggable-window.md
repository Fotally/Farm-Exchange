# DraggableWindow 接口

对应 `scripts/ui/DraggableWindow.cs`。它是当前二级窗口共同的容器；构造时给出节点名、标题、初始位置与尺寸以及可选关闭动作。`Body` 接收窗口内容，`ShowRaised()` 显示、抬到同级最前并限制在视窗内。

标题栏负责开始拖动，窗口自身处理移动与释放；视窗尺寸变化时再次限制位置。窗口实例在本次运行中保留，关闭和重新打开沿用上次位置。1080P 基准保留顶部 143、底部 180 像素给常驻状态及操作栏，整体倍率同时作用于这些避让范围和窗口首选尺寸。尺寸取首选尺寸与当前可用范围的较小值，扩大视窗后恢复首选尺寸。标题栏、关闭按钮和正文节点仍分别命名为 `Header`、`CloseButton`、`Body`，真实设施类型通过内部 `SetTitle` 更新单行标题。

主场景通过内部 `SetInitialPlacement` 将详情靠右、其余经营窗口居中。首次定位和尚未被玩家拖动的窗口随视窗重新靠边或居中；用户拖动后保留位置并限制在可用范围。独立使用时仍尊重构造给出的初始位置。窗口在挂树时接入 [UiScaling](../ui-scaling/interface-ui-scaling.md)，订阅倍率和视窗变化，退出时取消订阅。

纸面木框主题直接设置在每个窗口，独立场景测试同样取得主题。窗口将 `Body` 放入 `WindowScroll`，长正文可在较矮窗口整体滚动；窗口内已有的商品、目录、条件列表等局部滚动继续保留。调用方不能把正文最小尺寸强制设置为整个视窗高度。关闭后终止拖动，正文选择、滚动和按钮操作不会开始标题拖动。

标题采用明确单行，初始化时关闭自动换行。标题节点首次尚未取得排版宽度时，也不能按零宽将中文标题纵向分行、临时抬高窗口最小高度；正文的正常换行与滚动不受影响。标题区包含低强调分类与关闭线条图标；`WindowTitleLabel` 保留标题节点身份。真实主场景验收至少使用 1920×1080，检查标题可抓取、正文可滚动和上下常驻操作区可达，不通过重新裁剪窗口尺寸掩盖子控件最小高度。

右侧 `DetailWindow` 按原型归一到 1080 高度：标题栏 84 像素，标题字号 24、分类字号 12，关闭按钮 34×34、图标宽 22。详情外框仍为 409×727，正文边距仍为 17。普通经营窗口保持标题栏 64、标题字号 19、分类字号 9、关闭按钮 28×28 与图标宽 18。

`Main` 不保存拖动中的窗口或复制边界计算；各具体窗口只维护自己的内容和操作意图。玩家操作见[主界面接口](../main/interface-main.md)。
