# DraggableWindow 接口

对应 `scripts/ui/DraggableWindow.cs`。它是当前二级窗口共同的容器；构造时给出节点名、标题、初始位置与尺寸，按需要配置避让底栏和关闭动作。`Body` 接收窗口内容，`ShowRaised()` 显示、抬到同级最前并限制在视窗内。

标题栏负责开始拖动，窗口自身处理移动与释放；视窗尺寸变化时再次限制位置。窗口实例在本次运行中保留，关闭和重新打开沿用上次位置。建造目录与作物选择窗口避让底部操作栏，其余窗口只受视窗边缘限制。标题栏、关闭按钮和正文节点仍分别命名为 `Header`、`CloseButton`、`Body`。

`Main` 不保存拖动中的窗口或复制边界计算；各具体窗口只维护自己的内容和操作意图。玩家操作见[主界面接口](../main/interface-main.md)。
