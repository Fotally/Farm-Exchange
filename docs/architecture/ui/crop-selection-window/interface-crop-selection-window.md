# CropSelectionWindow 接口

对应 `scripts/ui/CropSelectionWindow.cs`，继承 `DraggableWindow`。创建时一次建立七种作物按钮；`Refresh(FarmGame)` 更新原料当前报价和公共库存，`CropRequested(CropKind)` 向 `Main` 报告改种意图，不直接修改农田。

窗口名 `CropWindow`，按钮名 `CropCard` 加作物种类。重新打开和经营刷新沿用滚动位置、窗口位置及按钮实例；建造目录关闭时也不会销毁作物选项。

`SetManualMode(bool, Vector2I?)` 在打开窗口前设置立即改种或预备下一轮，以及用于播种提示的农田格。立即模式使用既有 `CropRequested`；预备模式使用 `NextCropRequested`，不复用立即改种命令。窗口在选作物前显示解除本田共享表、清空本田安排的说明；立即模式额外明确丢弃未收获作物并保留水分，预备模式明确保留当前轮。

两种接管告知都使用明确的两行文本。关闭自动折行，避免首次尚未布局时按窄宽度把告知撑成几十行，进而抬高窗口最小高度、触发范围校正而改变记忆位置。窗口尺寸和拖动边界继续由既有 `DraggableWindow` 管理，不在后续帧重设尺寸。

作物卡通过 `FarmGame.GetPlantingCheck` 显示当前禁生季节、预计越界风险或当前可播种；风险不禁用按钮，选择目标仍由经营入口处理。卡片只更新报价、库存和提示，保持原按钮与滚动位置。

该窗口的播种提示依赖打开时选中的真实农田。若玩家从仍可操作的详情面板移除此田，`Main` 在移除成功后先关闭选种窗口再刷新，立即与预备模式一致；窗口不查询已经删除的农田，也不通过吞异常处理失效选择。
