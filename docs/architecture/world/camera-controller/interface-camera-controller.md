# CameraController 对外接口

对应类型：FarmExchange.World.CameraController，代码位于 scripts/world/CameraController.cs。作为 Godot Camera2D 节点，它接收输入，使用 WorldMap.SelectAtScreenPosition 完成短按选格，使用 WorldMap.ClampGlobalCameraCenter 限制全局镜头位置。

左键按下到释放的移动距离达到 8 个逻辑视口像素时转为拖动，不再发出选格；释放立即结束拖动，即使释放事件被界面拦截，也在下一帧校正。中键拖动、滚轮缩放、WASD 和方向键移动由该模块处理。玩家倍率范围为 1.25～2 倍，开局为 1.25。

当前视口的真实焦点属于可编辑 `LineEdit` 或 `TextEdit`（含子类）时，WASD 和方向键只参与编辑，不产生键盘平移；`SpinBox` 实际聚焦的可编辑子 `LineEdit` 遵循同一规则。按钮、只读文本控件和无焦点仍允许原键盘平移。退出编辑后的下一帧恢复当前全局键态：仍持键则继续移动，在编辑期间释放则不残留移动。鼠标释放校正、短按、拖动和滚轮缩放继续按原路径处理。

`IsDragging` 只读报告左键实际拖动或中键拖动，`Main` 用它隐藏放置预览；左键尚未达到阈值不算拖动。`IsMouseInsideWindow` 由窗口进入/离开信号维护，供协调入口决定预览可见性；离窗清除鼠标按下与拖动状态，退出场景取消窗口信号订阅。

`MapShortClicked(Vector2)` 在已通过界面和拖动检查的左键释放处、原 `WorldMap.SelectAtScreenPosition` 前通知逻辑视口像素位置，包含地图外位置；道路工具据此提交越界整段并显示实际拒绝原因。`Main` 的普通选择信号在道路工具期间只清选择并返回，避免同次短按执行两次道路命令。

`MapPointerMoved(Vector2)` 只在 `_UnhandledInput` 的真实鼠标移动、左键未按住且左／中键未拖动时通知。按住但尚未达到阈值也不通知，避免随后变为拖镜头的运动污染铺路轨迹。界面接收的移动不会通知；松开、滚轮、窗口、键盘和逐帧更新不冒充鼠标轨迹。Main 在退出场景解除两个通知订阅，详细状态规则见[道路操作](../../../gameplay/land/roads.md)。

原始 `_Input` 按下先清除上一轮左键意图，只有进入 `_UnhandledInput` 的地图按下才登记新点击。因此 UI 按下后地图松开不能确认；地图按下在 UI 松开由原始释放清除，不能留下下一轮点击意图。中键释放被界面截获时也停止拖动，逐帧物理按键检查继续校正左/中键状态。右键交由 `Main` 统一取消摆放，不由镜头消费。

## Module 与 Interface

`CameraController` 是显示与输入的 Module：场景配置初始位置、初始 `Zoom`，提供同级 `WorldMap`；引擎传入视口尺寸变化和输入。窗口适配、倍率限制、鼠标拖动换算、键盘编辑焦点归属、键盘速度和镜头位置限制由同一 Implementation 完成。调用方不需要按顺序执行“读窗口比例、重设倍率、重新限制位置”，各编辑窗口也不发送镜头启停命令。`Main` 和 UI 不持有第二份玩家倍率，也没有新增配置或适配命令。

运行后 `Camera2D.Zoom` 是抵消视口拉伸后的引擎倍率，不再直接表示玩家倍率；初始场景值只用于初始化内部玩家倍率。正常操作通过已有滚轮输入完成，不在场景协调或 UI 中直接改写运行时 `Zoom`。全局镜头位置仍沿用 `Camera2D.GlobalPosition`。

## Implementation 与验收

Module 内部唯一保存玩家倍率；初始化及视口尺寸变化时，按视口拉伸比例换算引擎倍率。窗口放大时同一倍率下格子、设施及人物的屏幕像素大小保持，镜头中心与玩家选择保持；退出场景时取消视口尺寸订阅。UI 的既有画布拉伸方式保持。

拖动使用逻辑视口位移及引擎倍率，键盘移动使用玩家倍率，让同一物理鼠标拖动距离和相同键盘时长的地图位移不随窗口大小改变。尺寸变化只更新镜头，`WorldMap` 通过已有画布变化检测更新块可见性，经营状态不变。

每帧先校正左键与中键的物理释放状态，再通过 `Viewport.GuiGetFocusOwner()` 读取实际可编辑焦点。GUI 消费按键不会清除全局键态，因此在生成键盘方向前判断焦点；不缓存焦点、不扫描控件树，也不维护额外的按键按下集合。

`TestCameraInteraction.RunChecks` 检查既有选择、拖动释放及边界；`RunResizeChecksAsync` 在真实 Main 中保持镜头自动处理，通过 GUI 焦点、公开 Input 事件和实际 SceneTree 处理帧验证年度表名称、库存底线数字编辑时镜头零位移，释放名称焦点或隐藏数字窗口后持键恢复平移，按键释放后停止。另用受控 0.1 秒处理检查原速度、WASD、方向键、Ctrl+A、实际窗口切换与持键进出编辑，同时验证 `TextEdit`、`SpinBox` 子编辑框、按钮与只读焦点，以及编辑期间的鼠标释放和缩放。该入口继续检查 1280×720、1920×1080、2560×1440、3840×2160 及往返、玩家缩放保持、上下限、UI 比例、点击、拖动、键盘平移与大窗口冷启动。有窗口运行另检查真实全屏，并保存窗口和全屏截图；汇总套件等待异步检查与窗口恢复完成。注入按键可以证明编辑焦点的输入归属，不能替代操作系统中文 IME 组合窗口验收。

它不计算等距坐标、不修改经营状态；输入的玩家可见行为见[地图与操作](../../../gameplay/world/map-and-camera.md)。tests/integration/TestCameraInteraction.cs 检查镜头与地图协作。

表现诊断通过内部 PlayerZoom 读取模块持有的真实玩家倍率；它不是抵消画布拉伸后的 Camera2D.Zoom。Main 只在检测到实际视图变化且局级 ViewChanged 入选时记录，不改变镜头输入或缩放规则。
