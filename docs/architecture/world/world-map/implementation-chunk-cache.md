# WorldMap 分块缓存实现

对应[WorldMap 对外接口](interface-world-map.md)的地图表现与 SyncFromGame。地图按 8×8 格划成 48×48 个块，每块缓存自身的视觉状态和带顶点颜色的 ArrayMesh。块尺寸是内部参数，不进入对外接口。

镜头或视窗变化时只更新块可见性，已绘制且外观未变的块复用缓存。SyncFromGame 先清空内部小格外观缓冲，按稳定锚点顺序每生产实例读取一次快照并填满对应占地，再比较 147,456 个小格外观，建筑、农田作物或作物阶段发生变化时标记相应块为脏；RemainingSeconds 数值不影响地图网格。可见脏块重绘，屏幕外脏块等进入视野时重绘。选中框和菱形边缘单独绘制，选格不重建地块。萝卜生长标记使用独立红橙色。

性能优化只延后屏幕外的绘制命令重建，不能延后 FarmGame.AdvanceTick 的经营计算。满地图负载与 FPS 口径见[构建与验收](../../../project/build-and-validation.md)；tests/unit/TestWorldMap.cs 和 tests/performance/ 验证坐标及负载。

工作中心由土地空间快照提供。每块缓存小格土地颜色与是否绘制中心标记；同一3×3设施即使横纵跨块，也只有工作中心所在块绘制作物或加工标记。地图边缘、块外接范围和单格顶点通过 `MapCoordinates.GridRectangleOutline/GridRectangleBounds` 统一获得。选框独立解析当前小格的空间快照，只绘制没有相邻占地偏移的边，整座拆除后不留旧九格选框。

FPS报告分别记录16,384生产实例与147,456占用小格；人物速度增至3小格/秒后，测试镜头跟随三人平均经营位置并叠加±200世界像素水平往返，确保采样前后画面包含三名移动工人。轨迹变化在报告中明确记录，不能将结果与旧固定中心±500轨迹作同条件比较，FPS/P95、时长和实体数量门槛不变。
