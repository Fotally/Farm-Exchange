# 地形与完整路线 Interface

关联 [#110](https://github.com/Fotally/Farm-Exchange/issues/110)，履行[水域方案](../../project/water-terrain-proposal.md)；配置见[配置 Interface](interface-terrain-rules.md)，实现见[静态地形实现](implementation-static-terrain.md)。

`TerrainMap` 是地形 Module，唯一拥有本局共享水角、独立种子、不可变配置、权威岸线和原生导航资源。建筑占用、任务与实际移动进度仍归原模块所有。静态模板可共享，每局地图 RID 和分块区域 RID 独立。

| Interface | 调用方约定 |
| --- | --- |
| `CreateAsync(seed,rules,tree,cancellationToken)` | 主线程加载静态岸线模板，纯 CPU 候选生成在后台运行并响应取消；回主线程分帧构建保守障碍，以原生 Clipper／三角化将连续导航面按既有地块分区，再在本局地图快照切换事件中确认全部登记区域就绪。没有固定“两帧必就绪”约定。开局准备期间不得推进经营。纯陆地由同一入口立即完成，允许 `tree=null`；首次建路由下述更新入口准备原生地图。失败不发布半成品，同步事件订阅在成功、取消或失败时全部解除 |
| `Create(seed,rules)` | 仅接受显式纯陆地；调用上述同一完整实现，不阻塞等待原生导航。含水配置明确拒绝并要求异步入口 |
| `Dispose()` | 局拥有者在局结束释放地图与区域；可重复调用。释放后不再求路 |
| `GetCell(cell)` | 四角依次为顶、右、底、左；水／土／草编码 0／1／2，三元权重 1／3／9／27。越界明确拒绝 |
| `IsFullLand(cell)` | 四角无水，地图外为 false。含水岸格不能建造，仍可存在可行走干地 |
| `FindLandPath(start,target)` | 返回 `Success` 与完整不可变 `LandPath`，或 `InvalidStart`／`InvalidTarget`／`Unreachable`；不交付引擎部分路径，不将投影位置当作真实起终点。原生路径未通过完整扫圆检查时明确抛阶段异常 |
| `IsNavigationReady` | 该地形提交的最新道路快照已完成准备且未释放；土地刚发生变更但尚未提交给本模块的待准备状态由 FarmGame 拥有 |
| `UpdateRoadsAsync(spaces,tree,cancellationToken)` | 主线程串行接收土地拥有的完整只读空间快照，只派生道路锚点。相同道路集合立即完成；不同集合只重分组受影响块的既有静态面并等待本地图及全部变更区域的新迭代。首次纯陆地建路建立同一连续原生网格。准备期间求新路线明确抛异常，已领取的不可变 LandPath 不变；取消或失败释放该地图并传播，不能回退旧路线 |
| `IsAllLand`／`PondCount`／`WaterArea`／`CandidateCount` | 只读诊断。水面按最终有理岸线面积计算，不等于含水禁建格数 |

导航采用 Godot 原生 A* 与 Funnel；圆脚底仍读取配置半径，数值安全余量固定为 `1/256` 格。2026-10-14 确认原生 RDP `1/32` 格保守简化及额外离岸 `1/8` 格；简化只用于导航，完整陆地、面积与真实水域分类仍读取原岸线。简化误差补偿另含一个 `1/4096` 格导航 CellSize，合并为一次 Round 外扩；默认总外扩为 `0.285400390625` 格。创建时以原生 Clipper 完整认证该障碍包含原岸按“脚底＋数值余量＋额外离岸”外扩的区域，失败明确拒绝。因此不保证所有略宽于圆直径的缝隙都能通过，旧近岸干地点也可能不属于导航区域；不能把它投影到附近可行走点。建筑不阻路；静态面只构建一次，道路建拆只改变原生区域归组，没有自写可见图、沿岸逐点绕行或失败替代算法。

道路区域的 `travel_cost=1`、普通地面为 `2`，五种道路材质相同，工人仍每经营秒移动3格。偏好由原生区域成本决定，不保证每条附近短路都会被选中，也不承诺加权全局最优。土地提交后、最新原生快照完成前，FarmGame与真实宿主停止推进完整经营tick；已领取行程保持，后续领取读取最新道路。道路占用及费用仍归土地与经营，导航不另持有业务道路状态。

地图及各成本区域均使用引擎同步迭代开关，在正常服务器轮中成组发布，防止新旧成本区域短暂重叠；几何准备仍分帧，完成仍等待真实MapChanged及本次全部区域迭代改变。该选择不调用ForceUpdate，不改变脚底、离岸距离或完整端点门限。

完整裁剪轮廓先按既有步长对齐并仅去除严格相等的连续点，再原生三角化，避免生成后对齐使面塌缩。原生三角形随后循环轮换起始索引，使最短边先出现，以改善固定引擎端点投影的数值条件；不改顶点坐标、朝向、有向边、几何或通路。端点仍受相同精度门限和真实圆脚底验证约束。

完整创建还审计所有未配对完整边确为水障碍或地图外框边界，并逐个验证所有完整陆地建筑工作中心都位于保护区中心同一原生连通分量；失败抛出阶段异常，不修面或发布不可达工作中心的地图。内部边连接及空间索引仅用于验证，调用方仍只使用原生完整路线查询。Dispose内部取消正在运行的道路准备；分帧与事件等待被终止，释放后不能再次求路。

`LandPosition` 保存有限 `double` 基础格坐标，值比较比较两个分量。`FromCell` 是整数格中心；`FromCoordinates` 保留传入的有限双精度值；`FromVector2` 明确接收引擎单精度值。运行时取消保留原 `LandPosition`，不从显示坐标重新构造。

`LandPath` 保存去除连续重复点后的折线和每段 `max(|dx|,|dy|)` 的 double 累计距离；整趟距离除速度后一次向上取整。经营使用整数累计移动距离采样，超过总长返回原始终点；表现使用 double 重载和同一路线方向。没有每次接续增加分母的有理运行坐标。单秒与批量从同一路线、同一累计整数距离采样；到达秒不作业的规则仍由调度器维护。

端点允许的原生舍入校正不超过一个导航 CellSize；路线始终包含真实请求起终点，校正连接段也参与扫圆验证。这里的有限精度校验不被描述为对所有真实几何的全局误差证明。

真实起终点按圆半径检查距岸后，使用圆内小方框与原水域的原生 Clipper 交集判定水内外，避免引擎射线经过共享顶点时的奇偶误报；该方框不参与移动碰撞形状。路径内部通过地图界限和全部连续线段扫圆核验，不能跳过中间岸线。

**Depth**：完整准备、原生查询、端点与净空核验、释放都封装在地形。**Locality**：岸线及导航知识不扩散到工人和表现。**Seam**：调用方与测试使用相同创建和完整路线入口。
