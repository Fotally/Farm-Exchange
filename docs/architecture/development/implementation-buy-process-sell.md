# 买入加工委托卖出实现

履行[参数化固定流程接口](interface-parameterized-scenario.md)。源码 [BuyProcessSellScenario.cs](../../../scripts/development/scenarios/BuyProcessSellScenario.cs) 只组织正式命令与公开快照；加工、领取、报价、冻结、成交和手续费由现有业务模块决定。

## 固定状态推进

准备完成后记录基准，调用 `FarmGame.Buy(raw,Q)`，紧邻命令检查成功数量、原料总量增Q、金币减少真实货值、零费用及冻结不变。拒绝立即停止，独立局也不赠送资金或原料。

随后进入加工观察。每个真实事件或请求终点查询目标场地；观察到 `Processing` 后进入产品等待。两阶段从买入后的第一个完整tick共同累计一个加工预算，达到Q份可用产品后才能建单。独立局使用实际 `Produced` 汇总、原料清零、Q份产品及场地等待原料状态核对受控加工关系。Q大于1时由业务逐批完工和领取，流程不按配置计算批次，也不把首次产出当作完成。

现场可以已有批次或可用产品。记录目标真实状态，但不把已有批次归因于本次买入；产品已经达到Q但未观察到目标加工时，该项记录证据不足。不清理现场来构造“严格成功”。

产品满足后创建一次固定卖单：Sell、Once、Fixed、数量Q、预算None、金额保留0、唯一条件为商品总库存大于等于Q。紧邻建单前后核对返回ID、Waiting、本单冻结Q、商品总量不变、可用减少Q和资金不变。本单从随后经营tick由真实订单模块执行。

订单等待阶段只观察返回ID。撤销、停用或修改本单请求即终止，保留真实状态，不重建原单。完成后检查真实LastFill商品、方向、数量与成功结算，本单冻结归零；独立局核对净余额变化等于真实货值减费用，库存全部卖出且总量等于可用加冻结。现场整段资金及生产归因保留证据不足。

## 日期与预算相遇

日期字符串只接受游戏 `yy-MM-dd`，年01至99、月01至12、日01至28。日期起点换算为首次达到它的完整经营tick，采用现有每秒7单位、每日360单位的比例，不使用公历日期。

`GetMaxAdvanceTicks` 把下一日期边界与剩余等待预算合并限制推进。检查点按实际日历差额累计等待tick；报告区间按批量真实事件及请求终点记录，不生成虚构的逐tick证据。

同一完整检查点先观察已有本单成交，再检查最后日期。末日期本单完成可以成功；产品此时才达到Q则报告时间范围耗尽，不创建新单。加工预算最后tick达到Q允许建单，订单预算最后tick完成允许成功。加工观察与等待不重置预算。中间日期边界进入下一段倍率，返回宿主重算推进，不直接设日期。

## 报告与验证

加载固定原文件引用和原始字节SHA-256，报告写入这些引用及真实运行记录，不复制参数。独立准备逐次记录正式拆除、建造、实际扣费和底线操作；现场记录绑定且未清理。暂停/倍率观察由唯一驱动宿主传入。

启动时接收已创建的唯一报告目录，将目录名固定为 `RunId`，创建局/报告关联后、调用 `Prepare` 前发出 `ScenarioStarted`。开始事件使用实际加载的修订和 SHA-256，之后外部文件变化不影响本次证据。独立局共享主场景 `RuntimeLog`，新建独立局身份；原地流程使用主局身份。

`Finish` 当场捕获最终公开状态，再发出一次 `ScenarioFinished`。序列化不重新查询游戏。`WriteReport()` 只使用启动时的目录，输出 `FileMode.CreateNew` 防止覆盖已有报告；成功记录 `ScenarioReportSaved`，异常记录 `ScenarioReportSaveFailed` 后原样抛出。窗口显示真实输出错误，不替换目录或将执行通过假称为已保存。报告保存失败不改变 `Outcome/Reason/Final`，也不生成第二条流程终结。

窗口用同一幂等报告尝试入口处理正常完成、中止和宿主退出；退出入口不再访问子控件。独立局在保存成功或失败后释放日志，确保报告事件先于 `GameEnded`；原地流程始终保留主局。公共 Adapter 只持流程日志关联和终结去重，不拥有执行、配置或报告文件操作，见[时间与流程日志](../logging/implementation-time-scenario-observation.md)。

[TestParameterizedScenario](../../../tests/unit/TestParameterizedScenario.cs) 通过真实共用驱动及公开经营接口验证严格配置、文件修改后参数固定、原始BOM摘要、Q=1与Q=3、倍率变段、暂停、现场已有批次/订单、手动改速中断、预算与日期边界、正式拒绝、底线阻塞、目标移除、撤单、中止、终止快照及路径/输出错误。长期用例保存在 [tests/scenario-configs/buy-process-sell](../../../tests/scenario-configs/buy-process-sell/)，复用现有TestSuite。

`TestScenarioLogging` 覆盖八种真实终结结果、实际加载凭据固定、提前 RunId、主局/独立局身份、同值选择中断顺序、报告成功/冲突失败及采集开关/写入故障等价；运行结果见项目验收记录。
