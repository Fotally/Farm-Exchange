## 要解决的体验问题

玩家在点击建造前，应能看清会占据哪些格子、能否放置、失败原因和本次费用。多格建筑的候选锚点空闲，不能代表整座设施可建；预览必须覆盖该建筑定义的全部占地。

## 用户已确认的设计

2026-10-03 用户确认以下要求，随后授权按此实施：

- 预览跟随鼠标，点击即正式建造。
- 所有可摆放类型建造成功后保持当前类型的摆放模式，可继续点击建造；失败也保持模式。
- 预览机制根据所选建筑的占地属性动态生成，不写死 3×3 或 1×1。两者仅是当前农田、加工场地和道路的属性值。
- 鼠标定位先沿用现有锚点：鼠标指向的基础格作为候选锚点，占地按建筑属性中的偏移相对该锚点展开。
- 道路先沿用逐次点击建造，每次按道路占地属性预览和提交一份占地。
- 右键取消摆放适用于所有可摆放建筑。右键、Esc 和取消按钮统一调用通用取消入口，由同一摆放流程处理。
- 占地冲突只将实际冲突的占地格标红，其他候选格保留正常预览；采用逐格反馈，不再使用整座红框、叉形图标或冲突斜线。
- 建造成功后，在保持摆放期间不弹出详情窗口。
- 摆放时保留左键短按建造、拖动平移镜头；拖动松开不建造。
- 鼠标移到界面上时隐藏地图预览，界面点击不穿透建造，移回地图恢复预览。
- 进入摆放保持玩家当前暂停状态，已暂停时也可以预览和建造。
- 可放置区域的绿色、透明度、线宽及锚点标记样式按参考案例确定，再通过画面检查调整，无需增加玩法规则。

“保持摆放”表示每次点击提交一座建筑，并继续预览下一座，不意味着按住鼠标连续生成建筑或批量规划。

## 实施前的规则与事实

已确认规则见[开局与建造](../../gameplay/land/opening-and-building.md)、[道路](../../gameplay/land/roads.md)及[地图与镜头](../../gameplay/world/map-and-camera.md)。

- 当前农田、加工场地的占地属性为 3×3 基础格，道路为 1×1；这些是现有规格，不是预览机制的固定尺寸。任意基础格可作锚点，不要求对齐三格跨度。
- 当前鼠标点击的格就是锚点；生产设施从该格沿两个格轴各延伸三格，中心工作格为锚点加 `(1,1)`。
- 生产设施每座 10.00 金币，道路每格 1.00。建造检查使用可用金币，委托冻结金额不能用于建造。
- 任一占地格越界或被占用都会拒绝整次建造；失败不扣费、不留下部分设施。执行时重新检查。
- 当前农田和加工场地成功建造后退出摆放并显示详情，道路成功后保持连续逐格铺设；失败保持摆放。
- 左键短按在松开时确认点击；移动达到既有拖动阈值后平移镜头，中键、键盘也能平移，滚轮缩放。
- 当前 `Main` 持有摆放类型；`FarmGame.CheckPlacement` 已提供只读预检，`TryPlace` 执行重验；地图没有跟随鼠标的放置预览。

## 基本流程

整体流程为“目录选类型 → 鼠标跟随预览 → 点击即建 → 保持摆放”，右键、Esc、取消按钮统一退出。

1. 选择建筑后收起目录和详情，显示当前类型、占地和取消入口。
2. 鼠标移动到地图时，以鼠标指向的基础格作为候选锚点，读取所选建筑的占地偏移，展示全部占地及该类型的半透明外观。
3. 候选位置变化时更新有效性；镜头平移、缩放、窗口尺寸变化后也按鼠标当前屏幕位置更新，避免预览位置滞后。
4. 左键短按在松开时对显示的候选位置执行建造。成功后保持当前类型，立即更新下一次候选位置、占用和可用金币的反馈；摆放期间不弹出详情窗口。失败保持预览并显示实际拒绝原因。
5. 右键、Esc 或取消按钮调用同一个通用取消入口，退出当前类型的摆放并移除预览，不扣费。

预览只是候选位置的展示：不登记占地、不冻结或扣除金币、不创建生产状态、不触发加工领取。点击成功后才沿现有入口完成这些行为。

## 视觉与反馈

用户要求冲突格标红即可，并授权参考经典游戏确定可放置表现。设计采用简洁的半透明占地预览：正常候选格使用淡绿色覆盖与细格线，实际冲突格改用红色覆盖。建筑类型外观保持半透明，原地图与已有设施仍可辨认。半透明程度、线宽与颜色深浅以后通过画面检查调整，本轮不锁定数值。

这是基于经典游戏的候选外观与红绿反馈进行的本项目适配；具体作品的一手证据及对象染色、局部染色的区别见[调研记录](../../research/build-placement-preview.md)。不将全部作品描述为同样的逐格实现。

| 状态 | 地图表现 | 简短文字示例 |
| --- | --- | --- |
| 可放置 | 按建筑占地属性生成淡绿色半透明覆盖和细格线，类型外观保持半透明 | `{建筑名称} · 占地 {占地格数} 格 · {费用} 金币` |
| 占地冲突 | 仅实际冲突格显示红色半透明覆盖，其他候选格保持淡绿色；原建筑仍清晰可见 | 标红格本身表达位置冲突；点击时沿用既有拒绝消息 |
| 部分越界 | 保留完整轮廓，不向地图内自动挪位；越界部分标红 | `无法建造：超出地图范围` |
| 可用金币不足 | 保持格子的空间有效性配色，费用提示标红并注明可用金额 | `需要 10.00 金币，可用 7.00` |
| 鼠标在界面上或离开窗口 | 隐藏地图预览，保留当前建造类型和取消入口 | 底部保留类型、占地、费用 |

地图占地预览采用逐格颜色反馈，移除原草案的勾、叉和冲突斜线。选择设施的黄色边框继续用于普通查看，进入摆放时清除旧选择，避免与候选占地混淆。空间上有可用格不代表整座可以建造，任一冲突仍拒绝整次操作。

底部固定显示建筑名称、占地、费用和操作提示，减少预览附近的信息遮挡。金币不足等不能通过占地格表达的问题使用简短文字提示。费用在无效位置仍显示类型的标准费用，不能把失败预检返回的 `0` 当作免费。

占地格数读取占地偏移数量；如显示宽高，则从占地属性计算。当前规格可展示为 3×3 或 1×1，但提示文字不能按建筑类别写成固定尺寸。

同时存在多个拒绝原因时，整体可放置结果使用现有预检返回的原因，不建立另一套 UI 判断优先级。冲突格标红属于位置反馈，不替代整次可放置检查；每个占地格依据实际占用显示，不能因整次预检失败而把全部格子标红。

## 交互细节

- **鼠标与占地**：先沿用“鼠标指向锚点格”，候选占地按建筑定义的偏移相对锚点展开。用小标记标出锚点，便于理解占地展开的位置；标记样式按参考案例设计，通过画面检查调整。
- **镜头拖动**：保留左键拖镜头。进入拖动后暂时隐藏预览，松开只结束拖动，不建造；恢复悬停后重新显示。中键拖动同样不建造。
- **缩放和平移**：继续使用现有镜头倍率、键盘与中键操作。鼠标不动但镜头移动时，预览仍须指向鼠标下的新世界格。
- **界面遮挡**：在按钮、窗口和界面栏上不显示地图预览，也不穿透建造；移回地图重新计算当前候选锚点并恢复预览。从 UI 开始的按下不能在地图松开时建造，从地图按下后在 UI 松开也不能建造。
- **暂停与经营**：进入预览不自动切换暂停状态；已暂停时仍可移动预览并主动建造。经营继续时，自动交易等引起的可用金币变化须反映到当前预览。
- **建造失败**：候选位置不自动迁移到附近空地，整座设施也不拆成可放置部分；显示拒绝原因，玩家自行移到其他位置。
- **道路（操作已确认）**：先沿用一次预览一份道路占地、逐次点击建造；按当前道路属性表现为单格。成段铺路不纳入本轮。

## 通用取消入口（已确认）

- 取消摆放属于整个摆放流程的统一操作，适用于所有可摆放类型；输入层将右键、Esc 和按钮意图交给同一个 `CancelPlacement()` 入口。
- 该入口统一清除当前摆放类型、候选锚点与预览，刷新摆放提示和取消入口的显示。
- 取消操作不根据农田、加工场地或道路分类，不在各建筑中分别实现右键处理；适用范围由是否正在摆放决定。
- 复用现有摆放状态和取消方法作为这项通用约定，不额外建立建筑专用取消模块。

## 占地属性驱动的机制约束（已确认）

- 当前复用 `BuildingFootprint.Get(所选建筑).Offsets` 作为占地数据来源。候选占地是“候选锚点加每个占地偏移”，预览、冲突标记与实际建造读取同一份定义。
- 覆盖格、外围轮廓和占地数量均从该定义生成，不能用“农田/加工画九格、道路画一格”的分支或固定宽高代替。
- 冲突与越界检查只针对定义内的实际占地格；外围轮廓从占地格的外侧边生成，不用固定 3×3 外框代替。
- 调整某建筑的占地规格时，修改占地定义即可让预览跟随变化；保持预览机制与具体规格分离，不新增一套预览专用尺寸配置。
- 本要求不扩展为可编辑任意形状的工具、旋转系统或新的建筑类型。

## 简洁的职责安排

实施沿用以下职责，不引入新的经营状态。

- `Main` 继续持有当前摆放类型和生命周期，统一接收确认与取消意图；右键、Esc 和按钮共用 `CancelPlacement()`，所有建筑使用同一取消约定。
- `WorldMap` 负责鼠标格定位、预览占地与类型外观；预览独立覆盖绘制，不写入生产地图块缓存。
- 可放置与失败原因复用 `FarmGame.CheckPlacement`，标准费用复用 `GetBuildingCostCents`，实际建造仍调用 `TryPlace`。
- 占地形状复用 `BuildingFootprint.Offsets`，按所选建筑动态读取；坐标转换复用 `MapCoordinates`，UI 不持有固定尺寸或第二份占地定义。
- `CameraController` 保留短按与拖动的识别。预览与建造不得从拖动事件或被 UI 接收的点击触发。
- 预览检查和绘制只处理本次候选占地；不因鼠标移动同步或遍历全地图。

## 实现验收标准

以下标准用于 #87 的实施验收，未通过前不记录为完成。

- 所有建筑预览的覆盖格、外围轮廓和占地提示均匹配所选建筑的占地属性及实际占地；任意锚点、跨地图块与地图边缘均正确。
- 鼠标指向的基础格与候选锚点一致，预览和点击建造使用同一锚点，不增加中央对齐的固定偏移。
- 用不同占地属性的数据验证预览生成，包含当前规格以外的矩形占地；不因此新增可建类型。仅调整定义即可改变预览、冲突标记和占地提示，不修改预览算法中的尺寸常量。
- 占用、越界、可用金币不足在点击前可见；多原因结果与实际预检一致，无效候选仍显示标准费用。
- 多格占地部分被占用时，仅冲突格标红，其余格保持正常预览；整体仍不能建造，不出现整座红框、叉形图标或冲突斜线。只因金币不足而失败时，不把空间可用格标成占用冲突。
- 单纯悬停、移动、取消、镜头操作均不改变金币、冻结金额、库存、设施数量或加工批次。
- 成功只建造并扣费一次；预检后资源变化由执行重验处理，失败资源零修改。
- 拖镜头、在 UI 点击及跨 UI 的按下/松开不误建；滚轮、键盘平移、窗口尺寸变化后预览无错位。
- 任意类型每次成功建造后均保持当前类型，更新下一次候选占用与余额状态，摆放期间不弹出详情窗口。
- 道路每次点击按自身占地属性建造一份，成功后继续摆放；本轮不实现成段铺设。
- 对所有可摆放建筑验证右键、Esc 和取消按钮均调用通用取消入口，清除当前摆放状态与预览；切换建筑类型后取消行为一致。
- 暂停时预览与主动建造可用；连续建造时可用金币变化及时反映。
- 保持现有地图性能门槛；悬停不能触发全地图重绘，图形验收保存有效、冲突、边缘及镜头操作截图。

设计阶段已核对案例来源与当前事实；功能、性能和导出验收由实施阶段按上述标准完成并记录实际证据。
