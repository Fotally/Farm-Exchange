# 天气规则配置来源

- `weather_rules.json` 为项目根据 GitHub issue #34 与 2026-10-11 用户确认编写的运行配置，不来自美术包。
- JSON 只保存自然预排的具名数值：10 年周期、候选间隔、持续时间、区域尺寸、数量上限与暂定多云／降雨权重 4:3；不拥有运行中天气状态。
- 状态：已接入 `scripts/weather/WeatherRules.cs`，四个导出预设均明确包含此文件。没有素材改图、画布、pivot 或外部授权依赖。
- 现行规则见 [天气](../../../docs/gameplay/world/weather.md)，修改数值时同步该表和必要验收；配置缺失或非法直接拒绝加载，不使用另一份默认数值。
